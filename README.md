# JAZMINE — ระบบจัดการออเดอร์และงานผลิตเสื้อ

คลังนี้เก็บตัวระบบ JAZMINE พร้อมแผน กฎการทำงาน และคู่มือภาษาไทย หน้าจอระบบใช้ภาษาลาวปนภาษาอังกฤษ

ปัจจุบันเป็นรุ่นทดลองก่อนเปิดใช้เต็มรูปแบบในร้าน ส่วนที่พัฒนาแล้วครอบคลุมรับออเดอร์ ราคาและส่วนลด งานกราฟิก งานผลิต รับเงิน คืนเงิน ส่งสินค้า เอกสาร PDF และค้นประวัติ ยังต้องทดลองกับพนักงานและอุปกรณ์จริง รวมถึงเตรียมข้อมูลและการติดตั้งของร้าน

## เปิดทดลองในเครื่อง

ต้องมี Node.js รุ่น 24 ขึ้นไป และ pnpm รุ่น 11.25.0 เปิดโฟลเดอร์ `JAZMINE` แล้วทำตาม [คู่มือเปิดระบบ](JAZMINE/HOW_TO_RUN_TH.md) หรือใช้คำสั่ง:

```sh
cd JAZMINE
pnpm install --frozen-lockfile
pnpm dev
```

จากนั้นเปิด `http://localhost:5173` และตั้งบัญชีเจ้าของเมื่อเปิดครั้งแรก เครื่องใหม่จะยังไม่มีออเดอร์หรือบัญชีผู้ใช้จากเครื่องเดิม

## ข้อมูลที่อยู่ในคลังนี้

เก็บโค้ด คู่มือ รูปตัวเลือกสินค้า ข้อมูลตั้งต้นที่จำเป็น และชุดทดสอบ ไม่เก็บฐานข้อมูลร้าน บัญชีผู้ใช้ รูปที่ผู้ใช้ส่งเข้า เอกสารที่สร้างจากออเดอร์ สำเนาสำรอง รหัสลับ หรือผลทดสอบในเครื่อง ไฟล์ `.env.example` เป็นเพียงตัวอย่างการตั้งค่า

GitHub ใช้เก็บและติดตามโค้ด การอัปโหลดครั้งนี้ยังไม่ได้เปิดเว็บไซต์ให้เข้าใช้งานผ่านอินเทอร์เน็ต
