# JAZMINE — เส้นทางการใช้งาน

สถานะ: แบบวางแผนรอบแรกสำหรับเจ้าของตรวจ

รหัส S01–S31 อ้างถึง `JAZMINE_SCREEN_MAP.md` ทุกเส้นทางใช้สิทธิ์จากตารางกลางและเก็บประวัติเมื่อเปลี่ยนข้อมูลสำคัญ

## F01 — เข้าสู่ระบบและเริ่มวันทำงาน

ผู้ใช้: เจ้าของและพนักงาน

1. เปิดหน้าเข้าสู่ระบบ S01 และใส่ชื่อผู้ใช้กับรหัสผ่าน
2. ถ้ารหัสชั่วคราวต้องเปลี่ยน ให้ไป S02 ก่อนเริ่มงาน
3. เข้าหน้าหลัก S03 ที่แสดงข้อมูลตามสิทธิ์
4. เจ้าของเปิดภาพรวมกิจการ; ADMIN เปิดงานออเดอร์; GRAPHIC และฝ่ายผลิตเปิดคิวงาน S11

หากเข้าระบบไม่ได้ ให้ข้อความเข้าใจง่ายและทางติดต่อเจ้าของ บัญชีที่ถูกปิดเข้าทำงานต่อไม่ได้ เมื่อสิทธิ์เปลี่ยน หน้าที่เปิดอยู่ต้องใช้สิทธิ์ใหม่ด้วย

ผลสำเร็จ: แต่ละคนเห็นงานที่เกี่ยวกับหน้าที่ตน

## F02 — เลือกลูกค้าหรือเพิ่มลูกค้า

ทางลัดสำหรับลูกค้าขาจรตามคำตัดสินล่าสุด: เปิด S08 โดยตรง → เลือกลูกค้าขาจร → กรอกชื่อและเบอร์ของงานนี้ → ตรวจกลุ่มราคาและแบรนด์ → ทำ F03 ต่อได้เลย โดยไม่ผ่านการเพิ่มรายชื่อลูกค้า หลังยืนยันสามารถเลือกบันทึกเป็นลูกค้าประจำที่ S07 ได้เอง ข้อมูลออเดอร์เก่ายังคงเดิม

ขั้นตอนด้านล่างใช้กับลูกค้าประจำหรือเมื่อต้องการเพิ่มรายชื่อประจำโดยตั้งใจ

ผู้ใช้: เจ้าของ/พนักงาน ADMIN

1. เปิด S04 ค้นหาด้วยชื่อหรือเบอร์โทร
2. ถ้ามีแล้ว เปิด S05 ตรวจว่าเป็นลูกค้าและแบรนด์ที่ต้องการ
3. ถ้ายังไม่มี เพิ่มชื่อ เบอร์ กลุ่มลูกค้า และข้อมูลแบรนด์ใน S05
4. ถ้าเบอร์ซ้ำ ให้เตือนและตรวจรายการเดิมก่อนเลือกว่าจะใช้หรือเพิ่มใหม่
5. เลือกแบรนด์ JAZMINE หรือแบรนด์ลูกค้า ตรวจรูปป้ายคอและเทปคอ
6. บันทึกแล้วเลือกสร้างออเดอร์ S08

ผลสำเร็จ: ออเดอร์ใหม่มีลูกค้า กลุ่มราคา และข้อมูลแบรนด์ที่ถูกต้อง การแก้ข้อมูลลูกค้าในวันหลังไม่เปลี่ยนข้อมูลที่ยืนยันในออเดอร์เก่า

## F03 — สร้างออเดอร์และคำนวณราคา

ผู้ใช้: เจ้าของ/พนักงาน ADMIN

1. เริ่ม S08 จากลูกค้า S05 หรือรายการออเดอร์ S06
2. ตรวจลูกค้า กลุ่มราคา ป้ายคอและเทปคอ
3. เลือกแบบเสื้อ คอ ผ้า และส่วนประกอบ รวมผ้ารายส่วนที่มีผลต่อราคา
   ใช้ปุ่มรูปภาพพร้อมชื่อเพื่อเลือกส่วนประกอบ และดูสถานะเลือกแล้วก่อนทำขั้นถัดไป
4. ใส่จำนวนซื้อและไซซ์ จัดของแถมให้ตรงไซซ์
5. ใส่ส่วนลดเปอร์เซ็นต์ แล้วส่วนลดจำนวนเงิน ใช้ร่วมกับของแถมได้
6. แนบหรือเลือกแบบตัวอย่างที่อนุมัติสำหรับออเดอร์
7. ไป S09 ตรวจราคา จำนวนผลิตรวม และข้อมูลที่ต้องใช้

ตัวอย่าง: ราคาก่อนลด 1,000,000 LAK ลด 10% เหลือ 900,000 แล้วลดอีก 50,000 เหลือ 850,000 LAK ของแถมรวมในจำนวนที่ต้องผลิตและส่ง

ถ้าจะพักงาน ให้บันทึกร่าง; ถ้าเป็นการแก้ร่างที่บันทึกไว้แล้ว ให้ใส่เหตุผลตอนบันทึก ถ้าผ้าหมด ข้อมูลราคาขาด หรือข้อมูลจำเป็นไม่ครบ ต้องแสดงเหตุผลและพากลับแก้ก่อนยืนยัน

ผลสำเร็จ: ได้ร่างที่ตรวจสอบได้ ราคาสุดท้ายไม่ติดลบ

## F04 — ใบเสนอราคา ยืนยันออเดอร์ และใบแจ้งหนี้

ผู้ใช้: เจ้าของ/พนักงาน ADMIN

ทางเลือกที่หนึ่ง:

```text
ร่าง S08 → ตรวจ S09 → ออกใบเสนอราคา S10 → กลับแก้ร่างหรือยืนยัน
```

ทางเลือกที่สอง:

```text
ร่าง S08 → ตรวจ S09 → ยืนยันโดยไม่ออกใบเสนอราคา → S07
```

ก่อนยืนยัน ให้ตรวจข้อมูลจำเป็น ผ้า ราคา และฉบับข้อมูลล่าสุดอีกครั้ง เมื่อสำเร็จได้เลขออเดอร์ถาวรและรายการใบแจ้งหนี้ พร้อมเปิดงานเตรียมผลิต

หาก PDF ยังเตรียมอยู่ S10 แสดง “กำลังเตรียมเอกสาร” ผู้ใช้ยังเห็นว่าออเดอร์ยืนยันสำเร็จแล้ว หากเตรียม PDF ไม่สำเร็จ ให้ลองเตรียมเอกสารเดิมใหม่ ไม่สร้างออเดอร์หรือเลขเอกสารซ้ำ

แก้ร่างหลังออกใบเสนอราคาแล้วต้องออกฉบับใหม่เมื่อจะใช้ข้อมูลใหม่ เอกสารเดิมยังเปิดดูประวัติได้

ผลสำเร็จ: ยืนยันออเดอร์ครั้งเดียว มีใบแจ้งหนี้ที่อ้างถึงข้อมูลฉบับถูกต้อง ใบเสนอราคาไม่ถูกนับเป็นยอดขาย

## F05 — แก้ออเดอร์ทุกช่วง

ผู้ใช้: เจ้าของ/พนักงาน ADMIN

1. เปิดออเดอร์ S07 เลือกแก้ S08
2. แก้รายการที่ต้องการ ก่อนหรือหลังเริ่มผลิตได้
3. ไป S09 ดูข้อมูลเก่าเทียบใหม่และราคาล่าสุด
4. ตรวจยอดรับแล้ว คงเหลือ/เงินเกิน และฝ่ายผลิตที่ได้รับผลกระทบ
5. ใส่เหตุผลและยืนยันบันทึก
6. กลับ S07 ดูประวัติฉบับใหม่; ออเดอร์ที่ยืนยันแล้วมีใบแจ้งหนี้ฉบับใหม่เมื่อแก้ข้อมูลการค้า
7. ถ้ากระทบการผลิต ให้แจ้งแผนกที่เกี่ยวข้องและจัดทำใบผลิต/ไฟล์ฉบับใหม่ตามความจำเป็น

ตัวอย่างราคาเพิ่ม: ราคาใหม่ 1,200,000 รับแล้ว 500,000 → ค้าง 700,000 LAK

ตัวอย่างราคาลด: ราคาใหม่ 800,000 รับแล้ว 1,000,000 → เงินเกิน 200,000 LAK รอเจ้าของจัดการ ไม่มีการคืนเงินอัตโนมัติ

ถ้าคนอื่นแก้ออเดอร์ไปก่อน ให้ตรวจฉบับล่าสุดก่อนบันทึก ไม่เขียนทับประวัติ ของที่ทำแล้วต้องยังตรวจสอบได้ และจำนวนที่ส่งจริงแล้วห้ามหายเพราะแก้ออเดอร์

ผลสำเร็จ: ข้อมูลล่าสุดใช้ทำงานต่อได้ และรู้ว่าใครแก้อะไรเพราะเหตุใด

## F06 — จัดทำและอนุมัติไฟล์กราฟิก

ผู้ใช้: พนักงาน GRAPHIC

1. เปิด S11 มุมมองงานกราฟิก เลือกงาน S13
2. ตรวจแบบอ้างอิง ข้อมูลเสื้อ ไซซ์ แบรนด์ และส่วนที่ต้องทำไฟล์
3. จัดทำ/อัปโหลดไฟล์แยกส่วน ดูภาพตัวอย่างเต็มภาพ
4. ตรวจความครบและอนุมัติความพร้อมไฟล์สำหรับผลิต
5. กลับ S12 เห็นไฟล์ฉบับที่อนุมัติ ผู้อนุมัติ และวันเวลา

ถ้าไฟล์ไม่ครบให้คงร่างและแสดงรายการที่ขาด หากออเดอร์แก้จนกระทบไฟล์เดิม ให้ทำฉบับใหม่และตรวจอีกครั้ง ไม่เขียนทับไฟล์ที่เคยอนุมัติ

การอนุมัติไฟล์ผลิตไม่ใช่การบันทึกว่าลูกค้าอนุมัติแบบแทนลูกค้า และไม่ทำให้เริ่มผลิตโดยข้ามการเตรียมใบผลิต

ผลสำเร็จ: ฝ่ายผลิตมีไฟล์ที่รู้ชัดว่าเป็นฉบับพร้อมใช้งาน

## F07 — เตรียมใบผลิต

ผู้ใช้: ผู้มีสิทธิ์จัดทำใบผลิตตามกฎเดิม

1. เปิดออเดอร์ยืนยันแล้ว S07 → งานผลิต S12 → จัดทำใบผลิต S14
2. แบ่งจำนวนตามไซซ์ให้ใบผลิต หากต้องแบ่งส่งเป็นชุดอิสระให้แยกหลายใบผลิต
3. ตรวจแบบที่อนุมัติ ป้ายคอ เทปคอ และผ้าจากข้อมูลออเดอร์
4. แนบไฟล์กราฟิกฉบับถูกต้องสำหรับลำตัว แขน ปลายแขน คอ และส่วนอื่นที่มีจริง
5. ใส่หมายเหตุ ดูตัวอย่าง A4 และตรวจจำนวนที่จัดสรร
6. บันทึกร่างหรือกำหนดพร้อมผลิตเมื่อข้อมูลครบ

หากเปลี่ยนผ้าที่มีผลต่อราคาต้องกลับ F05 แก้ออเดอร์ ไม่เปลี่ยนราคาในใบผลิต การแบ่งใบผลิตต้องไม่ทำให้จำนวนปกติเกินออเดอร์และต้องนับของแถมด้วย

ผลสำเร็จ: ใบผลิตพร้อมใช้งานกับไฟล์และจำนวนที่ชัดเจน

## F08 — เดินงานตามแผนกจนพร้อมส่ง

ผู้ใช้: พนักงานฝ่ายผลิตในแผนกตน

```text
PRINTING → HEAT_TRANSFER → LASER → SIZE_SORTING → SEWING → QC
```

1. เปิดคิว S11 แล้วเลือกงาน S12 ที่พร้อมให้แผนกทำ
2. ดูใบผลิตฉบับปัจจุบันและไฟล์ก่อนเริ่ม
3. กดเริ่มงานในขั้นของตน
4. ทำงานและกดจบเมื่อผ่านเงื่อนไขขั้นก่อนหน้า
5. หากมีปัญหาไป F09
6. เมื่อ QC เสร็จ ของที่ใช้ได้และผ่านเงื่อนไขจึงนับเป็นพร้อมส่ง

งานเริ่มเหลื่อมกันได้ ตัวอย่างฝ่ายพิมพ์กำลังทำอยู่ ฝ่ายรีดเริ่มได้เมื่อเงื่อนไขครบ แต่ฝ่ายรีดกดจบไม่ได้จนกว่าฝ่ายพิมพ์จบ

งานปกติไม่ต้องกรอกจำนวนจบทุกขั้น ถ้าต้องแบ่งความพร้อมเป็นหลายชุดใช้หลายใบผลิต

ผลสำเร็จ: รู้ความคืบหน้าจริงตามขั้นและจำนวนพร้อมส่งที่ใช้งานต่อได้

## F09 — พบปัญหา ทำต่อ/หยุด และผลิตทดแทน

ผู้ใช้: ผู้ทำงานรายงาน; เจ้าของ/ADMIN จัดการปัญหา

1. จาก S12 เปิดรายงาน S15 ใส่รายละเอียด รูป และจำนวน/ไซซ์ที่เกี่ยวข้องถ้ามี
2. เลือกรายงานและทำต่อ หรือรายงานและหยุดงานที่ได้รับผลกระทบ
3. ส่งแล้วให้เจ้าของ/ADMIN เปิด S16 ตรวจปัญหา
4. ระบุวิธีแก้ จำนวนใช้ได้ เสียหาย และต้องผลิตทดแทน
5. ถ้าต้องทดแทน สร้างใบผลิตทดแทนเชื่อมปัญหาเดิม แล้วเดินงาน F07–F08
6. บันทึกผลและปิดปัญหา/อนุญาตทำต่อเมื่อพร้อม

รายงานทั่วไปไม่หยุดงานทุกส่วน แต่ถ้าเลือกหยุดแล้ว ต้องรอผู้มีสิทธิ์ดำเนินการของส่วนที่หยุด ของใช้ได้บางส่วนยังไม่เท่ากับพร้อมส่งจนผ่านเกณฑ์ QC

ผลสำเร็จ: ประวัติของเสียและงานทดแทนยังอยู่ จำนวนพร้อมส่งไม่รวมของเสียซ้ำ

## F10 — รับมัดจำหรือรับเงินเพิ่ม

ผู้ใช้: เจ้าของ/พนักงาน ADMIN

1. เปิดออเดอร์ที่ยืนยันแล้ว S07 → รับเงิน S17
2. ตรวจยอดปัจจุบัน รับสุทธิแล้ว และคงเหลือ
3. เลือกจำนวนที่จะรับ ไม่มีมัดจำขั้นต่ำตายตัว
4. เลือก LAK/THB/USD และเงินสด/โอน ใส่วันเวลาและอ้างอิงเมื่อมี
5. ถ้ารับสกุลอื่น ให้แสดงอัตราที่เจ้าของกำหนดและมูลค่า LAK ก่อนบันทึก
6. ใส่เหตุผลตามกฎการเปลี่ยนยอดเงิน ตรวจและยืนยัน
7. ไป S18 เห็นรายการและยอดสุทธิใหม่ พร้อมใบเสร็จของรายการนั้น

ถ้าไม่มีอัตราสำหรับสกุลที่เลือก ให้แจ้งติดต่อเจ้าของ S29 ไม่เดาอัตราและไม่ให้พนักงาน ADMIN เปลี่ยนเอง กดซ้ำหรือเน็ตหลุดต้องตรวจผลรายการเดิมก่อนสร้างซ้ำ

ผลสำเร็จ: ยอดเงินถูกต้องทั้งสกุลเดิมและ LAK พร้อมอัตราที่เก็บกับรายการ การรับเงินไม่เป็นเงื่อนไขเริ่มผลิต

## F11 — แก้รายการรับเงินผิด

ผู้ใช้: เจ้าของ/พนักงาน ADMIN

1. เปิด S18 เลือกรายการผิดและตรวจเลขอ้างอิง
2. ใส่เหตุผลและยืนยันยกเลิกรายการผิด
3. ไป S17 กรอกรายการที่ถูกต้องแล้วตรวจอีกครั้ง
4. กลับ S18 ดูรายการเก่าที่ถูกยกเลิกและรายการใหม่แยกกัน

ตัวอย่าง: บันทึก 500,000 แต่รับจริง 50,000 → ยกเลิก 500,000 พร้อมเหตุผล → บันทึก 50,000 ยอดสุทธินับเฉพาะรายการที่ใช้ได้

การแก้ตัวเลขบันทึกผิดต่างจากการคืนเงินจริง หากเงินจริงออกจากร้านต้องใช้ F12 และสิทธิ์เจ้าของ

## F12 — คืนเงินจริงเต็มหรือบางส่วน

ผู้ใช้: เจ้าของเท่านั้น

1. เปิด S18 → คืนเงิน S19
2. ตรวจรายการอ้างอิงและจำนวนที่คืนได้
3. กรอกจำนวน สกุลเงิน ช่องทางคืน และเหตุผล
4. ตรวจสรุปแล้วยืนยันตามการคืนเงินจริง
5. กลับ S18 ดูเงินคืนแยกจากรายการรับเดิมและยอดสุทธิหลังคืน

ไม่จำเป็นต้องออกเอกสารคืนเงินให้ลูกค้าในรุ่นแรก แต่เก็บประวัติภายในครบ ห้ามคืนเกินจำนวนที่มีสิทธิ์คืน

## F13 — เตรียมส่ง ส่งบางส่วน และลูกค้ามารับเอง

ผู้ใช้: เจ้าของ/พนักงาน ADMIN

1. จาก S07 หรือ S20 เปิด S21
2. ตรวจพร้อมส่ง ส่งแล้ว และจำนวนที่ยังส่งได้ แยกไซซ์
3. เลือกจำนวนครั้งนี้และวิธีรับ: ลูกค้ามารับเอง/ร้านจัดส่ง
4. กรอกผู้รับ ที่อยู่ และขนส่งตามความจำเป็น
5. ตรวจยอดค้าง หากยังไม่ครบให้เตือน ผู้มีสิทธิ์เลือกดำเนินการต่อได้
6. หากของยังอยู่ในร้าน บันทึกเตรียมส่ง; จำนวนส่งแล้วไม่เพิ่ม
7. ตรวจจำนวนล่าสุดแล้วกดยืนยันการส่ง → S22; เจ้าของ/ADMIN เลือกยืนยันล่วงหน้าแม้ของยังไม่ออกได้ พร้อมป้ายและเหตุผล แต่ยังต้องมีจำนวนผ่าน QC พอ
8. ดูยอดส่งและจำนวนคงเหลือ ออเดอร์ครบการส่งเมื่อยอดยืนยันตรงสินค้ารวมของแถมฉบับล่าสุดและไม่มีรายการเก่าที่ต้องตรวจ

ลูกค้ามารับเองต้องเลือกวิธี Pickup การส่งบางส่วนเก็บประวัติแต่ละครั้ง หากคนอื่นส่งบางส่วนไปก่อนให้ตรวจจำนวนใหม่ก่อนยืนยัน กรณียืนยันล่วงหน้าเป็นการบันทึกตามสิทธิ์ ไม่ยืนยันว่าของออกจริงแล้ว

ถ้าบันทึกผิด ยกเลิกรายการพร้อมเหตุผลแล้วเตรียมใหม่ ระบบเก็บประวัติเดิม การยืนยันล่วงหน้าที่ตั้งใจทำตามสิทธิ์ไม่ถือว่าผิดเพียงเพราะของยังไม่ออก

ผลสำเร็จ: จำนวนพร้อมส่ง/ส่งแล้วตรงกัน และรู้ว่าส่งขณะค้างเงินเท่าไร

## F14 — ลูกค้าติดตามงานและส่งคำขอ

ผู้ใช้: ลูกค้าที่มีลิงก์/QR ติดตามของออเดอร์

1. เปิดลิงก์ติดตาม → S23 ตรวจเบอร์โทรตามข้อมูลยืนยันในออเดอร์
2. ผ่านแล้วไป S24 ดูความคืบหน้ารวม พร้อมส่ง ส่งแล้ว และสถานะเงินแบบย่อ
3. ส่งคำขอทั่วไป ขอจัดส่ง หรือขอเร่งงาน
4. เจ้าของ/ADMIN เปิด S25 รับเรื่องและบันทึกผลพิจารณา
5. ถ้าตกลงส่งหรือเร่งงาน ผู้มีสิทธิ์ไปทำรายการที่ออเดอร์/การส่งแยกต่างหาก
6. ลูกค้าเห็นผลคำขอใน S24

เบอร์ไม่ตรงหรือลิงก์ใช้ไม่ได้ให้ข้อความทั่วไปที่ไม่เผยข้อมูลลูกค้าคนอื่น คำขอไม่เปลี่ยนความเร่งด่วนหรือส่งสินค้าให้เอง และไม่เปิดรายละเอียดภายในโรงงาน

## F15 — เจ้าของกำหนดอัตราแลกเปลี่ยน ต้นทุน และดูรายงาน

ผู้ใช้: เจ้าของเท่านั้น

1. เปิด S29 กรอกอัตรา THB/USD ที่ต้องการใช้และตรวจทิศทางการแปลง
2. บันทึก ผู้รับเงินใช้ค่านี้ต่อไป; รายการเก่าเก็บอัตราเดิม
3. กรอกต้นทุนผ้า ค่าแรง หมึก/วัสดุพิมพ์ และต้นทุนอื่นเมื่อมีข้อมูลจริง
4. เปิด S26 เลือกช่วงรายงาน เห็นยอดขาย เงินรับ/คืน และยอดค้างแยกกัน
5. กำไรแสดงความครบของต้นทุน ถ้ายังขาดให้แสดง “กำไรยังคำนวณไม่ครบ”

ยังไม่กำหนดราคาหรือวิธีเฉลี่ยต้นทุนแทนเจ้าของ ตัวเลขกำไรจะพร้อมได้เมื่อทั้งราคา ปริมาณใช้ และวิธีคิดที่จำเป็นครบแล้ว

## F16 — จัดการพนักงานและข้อมูลเก่า

ผู้ใช้: เจ้าของเท่านั้น

- พนักงาน: S27 → สร้างบัญชี → เลือก STAFF และแผนก → ส่งรหัสเริ่มต้นตามวิธีที่กำหนด → พนักงานเปลี่ยนรหัส S02
- เปลี่ยนแผนก/ปิดบัญชี: S27 → ตรวจบุคคล → ยืนยัน → สิทธิ์เก่าสิ้นสุด; บัญชีที่ถูกปิดใช้งานต่อไม่ได้
- ข้อมูลเก่า: S30 → ตรวจรายการ → ใส่เหตุผล → เก็บถาวร หรือดูเงื่อนไขลบถาวรก่อนยืนยันตามกฎ

เจ้าของบัญชีสุดท้ายที่ใช้งานได้ต้องไม่ถูกปิดจนระบบไม่มีเจ้าของ เลขธุรกิจเดิมห้ามนำกลับมาใช้ซ้ำแม้ข้อมูลถูกลบตามเงื่อนไข

## F17 — ค้นหา สแกน QR และเปิดการแจ้งเตือน

ผู้ใช้: ผู้ใช้ภายในตามสิทธิ์

1. เปิด S31 ค้นหาหรือสแกน QR
2. ระบบระบุชนิดรายการและตรวจสิทธิ์ก่อนเปิด
3. ถ้าเป็นออเดอร์ไป S07; งานผลิตไป S12; เอกสารไป S10; การส่งไป S22
4. การแจ้งเตือนเปิดรายการที่เกี่ยวข้องตามสิทธิ์เช่นเดียวกัน

สแกน QR เพียงอย่างเดียวไม่ทำให้เริ่ม/จบงาน รับเงิน หรือยืนยันส่ง ลูกค้าใช้ QR ติดตามผ่าน F14 แทนการเข้าหน้าภายใน

## สิ่งที่ต้องตรวจในแบบร่างรอบต่อไป

1. อ่านแต่ละหน้าแล้วรู้ว่าต้องทำอะไรต่อหรือไม่
2. เจ้าของ ADMIN GRAPHIC และฝ่ายผลิตเห็นงานของตนชัดเจนหรือไม่
3. ราคา เงิน ของแถม และจำนวนส่งตรวจได้ก่อนยืนยันหรือไม่
4. การแก้หลังเริ่มผลิตแสดงผลกระทบและเหตุผลชัดหรือไม่
5. มีทางกลับไปแก้โดยไม่เสียข้อมูลหรือไม่
6. โทรศัพท์ใช้เส้นทางเดียวกันได้สะดวกหรือไม่

ผังและเส้นทางชุดนี้รอเจ้าของตรวจรับก่อนถือเป็นแบบหน้าจอที่ยืนยันแล้ว
