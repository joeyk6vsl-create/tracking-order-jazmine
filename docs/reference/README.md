# JAZMINE Reference Documents

## ลำดับการใช้

1. `JAZMINE_UI_DESIGN_SYSTEM_V1.md` — คู่มือหน้าตาหลักสำหรับระบบ JAZMINE
2. `apple-layout-guide.md` — แนวทางประกอบด้านความอ่านง่าย ภาษา Lao การรองรับหลายขนาดจอ และการเข้าถึง

## กฎสำคัญ

- เอกสารในโฟลเดอร์นี้ควบคุมหน้าตาและประสบการณ์ใช้งานเท่านั้น
- ห้ามใช้เปลี่ยนกฎราคา สิทธิ์ผู้ใช้ สถานะออเดอร์ การรับเงิน การผลิต หรือการส่งสินค้า
- ถ้าคู่มือสองไฟล์ต่างกัน ให้ใช้ UI Design System ของ JAZMINE
- ถ้า UI Design System ต่างจาก Phase 5 Final ให้ใช้ Phase 5 Final
- ถ้าความสวยงามขัดกับความถูกต้องของข้อมูล ให้เลือกความถูกต้องของข้อมูล

## ผลตรวจเบื้องต้น

UI Design System สอดคล้องกับ apple-layout-guide ในเรื่องหลัก เช่น:

- Noto Sans Lao
- ปุ่มกดง่ายและช่องกรอกอ่านง่าย
- สีฟ้าสำหรับการกระทำหลัก
- หน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์
- สถานะกำลังโหลด ไม่มีข้อมูล ผิดพลาด และสำเร็จ
- การใช้งานด้วยคีย์บอร์ด
- ไม่ใช้สีอย่างเดียวเพื่อบอกสถานะ
- ลดความซับซ้อนและหลีกเลี่ยงหน้าจอที่รก

ข้อสังเกตเพียงจุดเดียวคือ UI Design System ยังใช้ข้อความสถานะเดิมว่า Phase 5B มีงานเหลือ ขณะที่ `JAZMINE_PHASE_5_FINAL.md` ระบุว่า Phase 5 เสร็จแล้ว จึงให้ยึด Phase 5 Final สำหรับสถานะโครงการ
