# JAZMINE — PERMISSION MATRIX

**สถานะ:** กฎสิทธิ์ฉบับเริ่มต้น  
**วันที่:** 31 ตุลาคม 2026

## ความหมาย

- `ได้` — ทำรายการได้
- `ไม่ได้` — ระบบต้องป้องกัน แม้ผู้ใช้จะเปิดหน้าหรือส่งคำขอโดยตรง
- `เฉพาะแผนกตนเอง` — ทำได้เฉพาะงานที่อยู่ในความรับผิดชอบของแผนก
- `รายงานเท่านั้น` — แจ้งปัญหาได้ แต่ปิดหรือตัดสินปัญหาไม่ได้
- `รอตัดสินใจ` — ยังห้ามเปิดใช้งานจนกว่าเจ้าของจะกำหนดกฎ

## สิทธิ์หลัก

สำเนาเอกสารพร้อมสถานะ: ใช้สิทธิ์เดียวกับอ่านต้นฉบับ ใบเสนอราคา/ใบแจ้งหนี้/ใบรับเงินให้เจ้าของกับ ADMIN ใบผลิตให้เจ้าของ ADMIN และ GRAPHIC ตามเดิม ส่วนตั้งค่าเก็บอัตโนมัติใช้ archive.manage เฉพาะเจ้าของ ต้องใส่เหตุผล ระบบเก็บได้เฉพาะเมื่อเจ้าของเปิดนโยบายไว้และเงื่อนไขครบ การเก็บไม่ลบข้อมูลหรือเปลี่ยนยอดเงิน

ยกเลิกแผนใช้ต่องานผลิตทั้งชุด: เจ้าของ/ADMIN เปิดตรวจและยืนยันพร้อมเหตุผลได้ เมื่อผ่านเงื่อนไขทุกใบ ใช้สิทธิ์แก้ปัญหาผลิตเดิม GRAPHIC/แผนกผลิตไม่มีสิทธิ์ยืนยันหรืออ่านหน้าตรวจย้อนแผน แต่ยังดูประวัติการทบทวนและการย้อนในหน้าผลิตตามสิทธิ์เดิมได้ การย้อนไม่เริ่มงาน ไม่คืนเงิน ไม่ย้อนส่ง และไม่ข้ามการอนุมัติกราฟิกของแผนใหม่

QR รับเงิน LAK/THB: เฉพาะเจ้าของ ADMIN_PROMAX ใส่/เปลี่ยนรูป รายละเอียด เปิด/ปิด และดูประวัติการตั้งค่าได้ เจ้าของ/ADMIN ตรวจและแนบ QR ปัจจุบันในใบแจ้งหนี้ได้ แผนกอื่นไม่ได้สิทธิ์ส่วนนี้ การดาวน์โหลดใบเก่าที่มี QR ใช้สิทธิ์เอกสารเดิม ไม่ลบประวัติหรือแก้ไฟล์ย้อนหลัง การสแกนไม่บันทึกเงินอัตโนมัติ ดู `../JAZMINE/docs/PAYMENT_QR_TH.md`

PDF ที่ระบบเก็บไว้: ใบเสนอราคา/ใบแจ้งหนี้/ใบรับเงิน เจ้าของและ ADMIN ดูสถานะ ดาวน์โหลด และขอลองทำไฟล์เดิมพร้อมเหตุผลได้ ใบผลิตให้เจ้าของ ADMIN และ GRAPHIC ตามสิทธิ์อ่านประวัติ PS เดิม การลองทำไฟล์ไม่ใช่การแก้ธุรกิจหรืออนุมัติการผลิต ลูกค้าและฝ่ายผลิตทั่วไปไม่อ่านไฟล์ภายในจากลิงก์ตรงได้ การอ่านหรือลองใหม่ตรวจบัญชีปัจจุบันทุกครั้ง

ใบเสนอราคา: เจ้าของ/ADMIN ตรวจ ออกใบ เปิดประวัติ และพิมพ์ได้ ใช้สิทธิ์ออเดอร์เดิม QR เปิดเลขและฉบับเฉพาะผู้เข้าสู่ระบบที่มีสิทธิ์ GRAPHIC/ฝ่ายผลิตและบุคคลทั่วไปอ่านเอกสารการค้านี้ไม่ได้ การสแกนไม่ทำรายการ

QR ในใบแจ้งหนี้: เจ้าของ/ADMIN ตรวจลิงก์และพิมพ์ได้ ใช้สิทธิ์ออเดอร์เดิม GRAPHIC/ฝ่ายผลิตตรวจลิงก์ลับเพื่อแนบเอกสารการค้าไม่ได้ ลูกค้าสแกนได้เฉพาะหน้าติดตามและต้องยืนยันเบอร์ ไม่ได้สิทธิ์อ่านเอกสารการค้าภายในจากการสแกน

วงจรยกเลิกออเดอร์: เจ้าของ/ADMIN ยกเลิกได้หลังตรวจเงิน งานผลิตและรายการส่งพร้อมเหตุผล แต่เฉพาะเจ้าของระบุข้อตกลงยอดสุดท้าย คืนเงิน เก็บออเดอร์ หรือเปิดกลับจาก Archive การเก็บข้อมูลไม่ย้อนการยกเลิก ใบผลิตค้างให้ GRAPHIC/เจ้าของปิดหลังตรวจชิ้นงานตามสิทธิ์เดิม คู่มือ `../JAZMINE/docs/CANCEL_AND_ARCHIVE_ORDERS_TH.md`

## สิทธิ์ฝ่ายผลิต

การแก้จำนวนปัญหาที่ปิดแล้ว: เจ้าของ/ADMIN ทำได้ ต้องตรวจชิ้นงานและใส่เหตุผลทุกครั้ง ปรับหรือยกเลิกร่างทดแทนที่ยังไม่เคยออกใบพร้อมกันได้ เก็บประวัติเดิมทั้งหมด ส่วน GRAPHIC และพนักงานผลิตแก้จำนวนยืนยันไม่ได้ การปรับร่างไม่ข้ามสิทธิ์อนุมัติใบผลิตของ GRAPHIC/เจ้าของ ดูคู่มือ `../JAZMINE/docs/CORRECT_PRODUCTION_ISSUE_QUANTITIES_TH.md`

ขั้นใช้ต่องานหลังแก้ออเดอร์: เจ้าของ/ADMIN ยืนยันแผนจำนวนได้ GRAPHIC อ่านแผนได้ และ GRAPHIC/เจ้าของเป็นผู้อนุมัติร่างใบผลิตใหม่ให้พร้อม การทบทวนโดย ADMIN ไม่ข้ามสิทธิ์อนุมัติใบผลิต

## กฎเพิ่มเติม

1. การซ่อนปุ่มเป็นเพียงการช่วยให้หน้าจอเข้าใจง่าย ระบบต้องตรวจสิทธิ์อีกครั้งเมื่อผู้ใช้กดทำรายการ
2. พนักงานที่ถูกปิดบัญชีต้องออกจากระบบทุกอุปกรณ์
3. เปลี่ยนระดับหรือแผนกพนักงานแล้ว สิทธิ์ใหม่ต้องมีผลทันที
4. ต้องมีเจ้าของ `ADMIN_PROMAX` ที่ใช้งานได้อย่างน้อยหนึ่งบัญชีเสมอ
5. งานที่กระทบราคา เงิน ออเดอร์หลังยืนยัน การผลิตทดแทน หรือข้อมูลเก่า ต้องเก็บประวัติผู้ทำ วันเวลา และเหตุผล
6. พนักงานแผนก ADMIN สามารถดูยอดของออเดอร์ที่ต้องใช้ทำงานได้ แต่ไม่สามารถเปิดรายงานยอดขายรวมหรือรายงานกำไร
7. เฉพาะเจ้าของ `ADMIN_PROMAX` กำหนดหรือแก้อัตราแลกเปลี่ยนได้
8. เฉพาะเจ้าของ `ADMIN_PROMAX` ดูกำไรและกำหนดราคาต้นทุนได้ หากต้นทุนยังไม่ครบ ระบบต้องไม่แสดงกำไรเป็นตัวเลขสมบูรณ์

## สิทธิ์แผนก GRAPHIC

พนักงานแผนก `GRAPHIC` ทำได้:

- ดูข้อมูลงานที่จำเป็นต่อการจัดทำกราฟิก
- จัดทำและแก้ไขไฟล์กราฟิกสำหรับการผลิต
- อัปโหลดไฟล์งานกราฟิก
- อนุมัติว่าไฟล์กราฟิกพร้อมใช้ในการผลิต
- รายงานปัญหาที่พบในงานกราฟิก

พนักงานแผนก `GRAPHIC` ทำไม่ได้:

- เปลี่ยนราคา ส่วนลด หรือยอดรับเงิน
- แก้ข้อมูลออเดอร์ทางการค้า
- อนุมัติการคืนเงินหรือการส่งสินค้า
- ลบไฟล์กราฟิกฉบับเก่าที่เคยถูกใช้ในการผลิต

เมื่อมีการเปลี่ยนงานกราฟิกที่อนุมัติแล้ว ต้องสร้างฉบับใหม่และเก็บฉบับเดิมไว้เป็นประวัติ
