# สินค้าและชนิดผ้า — งานต่อจากลูกค้าประจำ

เจ้าของเปิดเมนู “สินค้าและชนิดผ้า” เพื่อเพิ่มชื่อ รายละเอียด และสถานะใช้งานได้ กดการ์ดเพื่อแก้ไข บันทึกก่อนจึงเพิ่มรูปจากเครื่อง ภาพรองรับ PNG / JPEG / WebP ไม่เกิน 128 KB แอดมินเปิดดูรายการได้ ส่วนฝ่ายผลิตยังไม่เปิดสิทธิ์ในหน้านี้

ภาพใช้ช่วยเลือกสินค้า ยังไม่ใช่ไฟล์งานผลิต รายการแบ่งครั้งละ 25 รายการ ตัวกรองประเภทใช้กับหน้าปัจจุบัน กดหน้าถัดไปเพื่อดูรายการเพิ่ม

ข้อมูลเก็บในฐานเดียวกับบัญชีและลูกค้า ไม่มีการลบรายการถาวร มีประวัติการแก้ไขและป้องกันการบันทึกทับฉบับที่คนอื่นแก้แล้ว ยังไม่รวมราคา ไซซ์ การจับคู่สินค้ากับผ้า สต็อกผ้า และหน้ารับออเดอร์ ส่วนเหล่านี้ต้องทำต่อก่อนใช้งานรับงานจริง

ไฟล์ที่เพิ่ม:

- `packages/contracts/src/catalog.ts` — กติกาข้อมูลสินค้าและชนิดผ้า
- `database/migrations/0003_catalog.sql` — ที่เก็บรายการและรูป ไม่แก้ข้อมูลเดิม
- `apps/server/src/catalog/catalog-service.ts` — ตรวจสิทธิ์ บันทึกข้อมูลและประวัติ
- `apps/server/src/catalog/catalog-controller.ts` — ทางเชื่อมระหว่างหน้าจอกับข้อมูล
- `apps/web/src/features/catalog/CatalogPage.tsx` — หน้ารายการ แบบฟอร์ม และการเพิ่มภาพ
- `tests/integration/catalog.test.ts` — ตรวจการบันทึก สิทธิ์ ภาพ และการแก้ทับ
