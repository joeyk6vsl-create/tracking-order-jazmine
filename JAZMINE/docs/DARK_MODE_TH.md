# โหมดมืดของ JAZMINE

## วิธีใช้

กดปุ่มรูปพระจันทร์ **Dark** ที่หน้าเข้าสู่ระบบหรือแถบบนหลังเข้าสู่ระบบ เมื่อเปิดโหมดมืด ปุ่มจะเป็นรูปพระอาทิตย์ **Light** กดอีกครั้งเพื่อกลับเป็นโหมดสว่าง บนมือถือจอแคบ ปุ่มจะแสดงเป็นรูปอย่างเดียวและยังมีคำอธิบายให้โปรแกรมอ่านหน้าจอ

ระบบจำการเลือกไว้ในเบราว์เซอร์เครื่องนั้น เมื่อเปิดใหม่จะใช้โหมดเดิม หากยังไม่เคยเลือก ระบบจะใช้การตั้งค่าจอของเครื่อง การเลือกบนเครื่องหนึ่งไม่เปลี่ยนเครื่องอื่น

หน้าใบผลิต ใบแจ้งหนี้ และ QR ที่เตรียมพิมพ์ยังใช้พื้นขาวกับตัวหนังสือเข้ม เพื่อให้เอกสารอ่านง่ายและพิมพ์ได้ตามเดิม รูปสินค้าและรูป QR ไม่ถูกเปลี่ยนสี

## ผลกระทบที่ตรวจไว้

งานนี้เปลี่ยนเฉพาะการแสดงสีและปุ่มสลับโหมด ไม่เปลี่ยนข้อมูลลูกค้า ออเดอร์ ราคา สิทธิ์ การรับเงิน หรือขั้นผลิต สีหน้าต่าง ๆ ใช้ชุดสีกลางเดียวกัน จึงไม่ต้องแยกกติกาสีไว้ในแต่ละหน้า เวลามีหน้าใหม่ควรใช้สีจากชุดกลางนี้

## หน้าที่ไฟล์

| ไฟล์ | ทำอะไร |
| --- | --- |
| `apps/web/src/features/theme/ThemeProvider.tsx` | จำโหมดที่เลือก อ่านการตั้งค่าจอ และทำปุ่มสลับโหมดที่ใช้ร่วมกัน |
| `apps/web/src/main.tsx` | ตั้งสีก่อนแสดงหน้าเว็บและครอบทุกหน้าด้วยโหมดเดียวกัน |
| `apps/web/src/App.tsx` | วางปุ่มในหน้าทำงานและหน้าติดตามออเดอร์ |
| `apps/web/src/features/auth/LoginPage.tsx` | วางปุ่มในหน้าเข้าสู่ระบบ |
| `apps/web/src/styles.css` | เก็บชุดสีกลางของโหมดสว่างและโหมดมืด รวมการจัดปุ่มบนมือถือและสีสำหรับพิมพ์ |
| `apps/web/src/features/*/*.css` | ใช้ชุดสีกลางกับกรอบและป้ายสถานะของแต่ละงาน โดยคงสีเอกสารพิมพ์ไว้ |
| `tests/e2e/theme-mode.mjs` | ทดลองสลับโหมด เปิดหน้าใหม่ จอมือถือ และสีเมื่อพิมพ์ โดยใช้ข้อมูลทดสอบแยก |

## วิธีตรวจด้วยตนเอง

เปิด `START_JAZMINE.cmd` ใหม่ จากนั้นกดปุ่ม Dark ที่หน้าเข้าสู่ระบบ เข้าสู่ระบบแล้วลองเปิดหน้าร่างออเดอร์ สินค้า และงานผลิต ปิดแล้วเปิดหน้าเว็บอีกครั้งเพื่อตรวจว่าโหมดยังเหมือนเดิม ลองกด Light เพื่อกลับเป็นแบบเดิม
