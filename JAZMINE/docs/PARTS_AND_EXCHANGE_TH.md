# ราคาแต่ละส่วนของเสื้อและอัตราแลกเปลี่ยน

งานต่อจากตารางราคาพื้นฐาน อยู่ในเมนู “ราคาและส่วนลด” เดิม ใช้บัญชีเดิม หยุดโปรแกรมเก่าแล้วเปิด START_JAZMINE.cmd ใหม่ก่อนทดลอง

## เจ้าของกำหนดอะไรได้บ้าง

- ราคาเพิ่มของแขน ปลายแขน และบ่าแต่ละแบบ คิดต่อเสื้อ 1 ตัว ว่างหมายถึงยังไม่ทราบ 0 หมายถึงไม่คิดเพิ่ม
- ค่าผ้าของแต่ละส่วน: เลือก “ยังไม่กำหนด” / “ไม่คิดเพิ่มค่าผ้า” / “คิดเพิ่มค่าผ้า” ถ้าเปิดให้คิดเพิ่ม กรอกราคาผ้าของส่วนนั้นแยกได้
- อัตรา THB และ USD กรอกด้วยตนเองว่าเงินต่างประเทศ 1 หน่วยเท่ากับกี่กีบ รองรับทศนิยมอัตรา 10 ตำแหน่ง ไม่ดึงราคาออนไลน์

ต้องใส่เหตุผลและบันทึกเป็นราคาฉบับใหม่ทุกครั้ง แอดมินอ่านและทดลองยอดได้ แต่เปลี่ยนราคาหรืออัตราไม่ได้ ข้อมูลราคาเดิมยังเก็บอยู่ ไม่มีการใส่ราคาหรืออัตราทดสอบลงข้อมูลจริงของเจ้าของ

## ทดลองคำนวณ

เลือกแบบเสื้อ ไซซ์ ผ้า แล้วเลือกส่วนประกอบที่ต้องการในตัวทดลอง เลือกแขน บ่า และปลายแขนได้ประเภทละหนึ่งแบบ ถ้าเลือกผ้าแยกของส่วนนั้น จะใช้เฉพาะผ้าที่เจ้าของเปิดไว้ในหน้าจับคู่ผ้า หากเปิดคิดเพิ่มค่าผ้าของส่วนนั้น ต้องเลือกผ้าแยกก่อนจึงจะคำนวณครบ กรณีไม่ได้เปิดคิดเพิ่มจึงไม่เพิ่มค่าแยกนี้ ขั้นยืนยันจริงต้องมีบ่า/ปลายแขนและแขนเสื้อตามกฎที่เพิ่มไว้ในคู่มือยืนยัน

ระบบรวมราคาพื้นฐาน + ไซซ์ + ผ้าตัวเสื้อ + ราคาส่วนประกอบที่เลือก + ค่าผ้าแยกที่เปิดคิดเพิ่ม แล้วคูณจำนวนที่คิดเงิน ลดเปอร์เซ็นต์ก่อนลดเงิน ของแถมรวมในจำนวนที่ต้องทำแต่ไม่เพิ่มยอดขาย ตัวทดลองไม่เพิ่มส่วนประกอบให้เอง จึงแสดงว่าเป็นยอดรวมเฉพาะส่วนที่เลือก

ถ้าส่วนที่เลือกยังไม่ทราบราคา ระบบแสดงรายการที่ขาดและไม่แสดงยอดเหมือนคิดครบแล้ว หากเลือกเงินบาทหรือดอลลาร์แต่ยังไม่ตั้งอัตรา ระบบจะแจ้งให้เจ้าของกำหนดก่อน

ฐานยอดเงินยังเป็นกีบ เงินต่างประเทศคำนวณจากยอดกีบหลังลด หารด้วยอัตราที่กรอก แสดง THB/USD 2 ตำแหน่งโดยปัดครึ่งขึ้น ใช้จำนวนเต็มความแม่นยำสูงในการคำนวณ ไม่ใช้เลขทศนิยมแบบลอยตัวมาหารเงิน เก็บอัตราที่ใช้และเลขฉบับราคาไว้ในผลทดลอง ข้อมูลราคาฉบับเก่าไม่เปลี่ยนตามฉบับใหม่

## ขอบเขตที่ยังเหลือ

ยังไม่ใช่การรับเงินหรือออเดอร์จริง ผลทดลองยังไม่บันทึกเป็นเอกสารทางการ งานถัดไปต้องทำกติกาซื้อ X แถม Y อัตโนมัติและเชื่อมหน้ารับออเดอร์ พร้อมเก็บสำเนาราคา อัตรา และรายการที่เลือก ณ เวลายืนยัน การรับเงินคนละสกุลหรือหลายครั้งเป็นงานส่วนรับเงินต่อไป ไม่มีการคำนวณกำไรเพราะต้นทุนยังไม่ครบ

## ไฟล์ที่เกี่ยวข้อง

- `packages/contracts/src/pricing.ts` — กติกาข้อมูลส่วนประกอบ อัตรา และผลคำนวณ
- `apps/server/src/pricing/pricing-service.ts` — รวมส่วนเพิ่มทุกส่วนและแปลงสกุลเงินจากระบบกลาง
- `apps/web/src/features/pricing/PricingExtras.tsx` — ช่องให้เจ้าของตั้งราคาและอัตรา
- `apps/web/src/features/pricing/QuoteParts.tsx` — ช่องเลือกส่วนประกอบและผ้าในตัวทดลอง
- `apps/web/src/features/pricing/PricingPage.tsx` — เชื่อมตัวเลือกเข้ากับหน้าราคาเดิม
- `tests/integration/pricing.test.ts` — ตรวจรวมค่าผ้าหลายส่วน เปิด/ปิดค่าผ้า อัตราทศนิยม การปัดเงิน และประวัติ

ราคาฉบับเดิมเปิดต่อได้โดยให้ช่องส่วนประกอบและอัตราเป็น “ยังไม่กำหนด” ไม่เปลี่ยนให้เป็นศูนย์ ไม่ต้องสร้างบัญชีใหม่ และไม่ต้องแก้ไฟล์ต้นฉบับที่เจ้าของแนบ

ผลตรวจ: ผ่านชุดทดสอบรวม 32 กรณี ตรวจส่วนประกอบหลายส่วน ค่าผ้าเปิด/ปิด ข้อมูลราคาไม่ครบ ส่วนประกอบซ้ำ อัตราทศนิยม การรักษาผลฉบับก่อน และสิทธิ์เดิม ผ่านการทดสอบเบราว์เซอร์เจ้าของตั้งราคาแขนยาวและอัตรา THB → เลือกส่วนประกอบ → คำนวณยอดหลังลด → แสดงเงินบาท พร้อมตรวจมือถือ 390 พิกเซลไม่ล้นหน้าจอ ตรวจชนิดข้อมูล รูปแบบโค้ด และ build ผ่าน ใช้ข้อมูลทดสอบแยกจากฐานที่เจ้าของใช้งาน
