# ป้ายคอและเทปคอของลูกค้าประจำ

## วิธีใช้

1. เจ้าของหรือแอดมินเปิด **ลูกค้าประจำ** แล้วสร้างลูกค้ารายนั้น เลือก “แบรนด์ลูกค้า” (ระบบเลือกให้เป็นค่าเริ่มต้นสำหรับลูกค้าใหม่)
2. เปิดหน้ารายละเอียดลูกค้า อัปโหลดรูปป้ายคอและเทปคออย่างละไฟล์ ไฟล์ที่แอดมินหรือเจ้าของอัปโหลดพร้อมใช้ทันที
3. เมื่อเปิดออเดอร์ใหม่และเลือกลูกค้ารายนั้น ระบบจะนำป้ายคอและเทปคอล่าสุดของเขามาใช้เอง ไม่ต้องแนบซ้ำทุกออเดอร์ เช่น เลือก Venus ก็ใช้ไฟล์ของ Venus
4. ลูกค้าขาจรที่กรอกชื่อและเบอร์เฉพาะออเดอร์ใช้ป้ายคอและเทปคอของ JAZMINE เจ้าของหรือแอดมินตั้งไฟล์กลางในเมนู **ไฟล์และงานกราฟิก** ครั้งเดียว
5. ในแต่ละออเดอร์แนบ **แบบตัวอย่าง** เพียงไฟล์ปัจจุบันหนึ่งชุด ถ้าแก้งาน ให้ส่งฉบับใหม่ ประวัติฉบับเดิมยังอยู่

ลูกค้าประจำที่สร้างไว้ก่อนหน้านี้และยังระบุว่าใช้แบรนด์ JAZMINE จะยังใช้ไฟล์กลางต่อไป หากต้องการป้ายคอและเทปคอของตัวเอง ให้แก้ข้อมูลลูกค้ารายนั้นเป็น “แบรนด์ลูกค้า” แล้วอัปโหลดไฟล์ประจำตัวก่อนสร้างออเดอร์ถัดไป ระบบไม่เปลี่ยนข้อมูลลูกค้าเก่าทั้งหมดให้เอง

ไฟล์รองรับ PNG, JPEG, WebP และ PDF ขนาดไม่เกิน 2 MB ต่อไฟล์ ก่อนยืนยันออเดอร์ ระบบตรวจว่าป้ายคอ เทปคอ และแบบตัวอย่างล่าสุดพร้อมใช้ครบ ไฟล์ของลูกค้าคนหนึ่งไม่ใช้ปะปนกับอีกคนหนึ่ง การแก้ร่างทำให้แบบตัวอย่างของออเดอร์นั้นต้องส่งใหม่ แต่ไม่ทำให้ไฟล์ที่เก็บในคลังลูกค้าหรือ JAZMINE หาย

หลังรับรุ่นใหม่ ให้ปิดโปรแกรมเดิมแล้วเปิด `START_JAZMINE.cmd` ใหม่เพื่อใช้หน้าจอและปรับที่เก็บไฟล์ตามรุ่นนี้ จากนั้นตั้งไฟล์ JAZMINE กลางก่อนลองออเดอร์ขาจร และตั้งไฟล์ประจำของลูกค้าแต่ละรายก่อนยืนยันออเดอร์ของเขา

## ใครทำอะไร

- เจ้าของและแอดมินจัดการลูกค้าและคลังไฟล์ อัปโหลดแล้วใช้ได้ทันที และอนุมัติไฟล์เก่าที่เคยค้างตรวจได้
- กราฟิกยังส่งแบบตัวอย่างได้ หากกราฟิกเป็นผู้ส่ง ไฟล์จะรอตรวจ เจ้าของ แอดมิน หรือกราฟิกมีสิทธิ์ตรวจพร้อมเหตุผล
- ฝ่ายผลิตอื่นไม่มีสิทธิ์เปลี่ยนคลังไฟล์หรืออนุมัติ; กราฟิกยังส่งไฟล์จากร่างแบบเดิมเพื่อรอการตรวจได้ แต่หน้าใช้งานใหม่ให้ตั้งป้ายคอและเทปคอผ่านคลังของลูกค้าหรือ JAZMINE

การอนุมัติแผนและงานผลิตเป็นขั้นตอนของฝ่ายกราฟิกอีกเรื่องหนึ่ง กติกา “อัปโหลดแล้วพร้อมใช้ทันที” ในหน้านี้ใช้กับไฟล์ที่เจ้าของหรือแอดมินอัปโหลดเท่านั้น

ออเดอร์เก่าที่เคยแนบไฟล์ตามวิธีเดิมยังอ่านได้ ประวัติออเดอร์ที่ยืนยันแล้วเก็บหมายเลขไฟล์ฉบับเดิมไว้ ไม่เปลี่ยนย้อนหลังเมื่อเปลี่ยนไฟล์ในคลัง การเปิดร่างเก่าที่ผูกลูกค้าแต่ตั้งแบรนด์ไม่ตรงกับข้อมูลลูกค้าปัจจุบัน ต้องเลือกลูกค้าใหม่ก่อนบันทึกหรือยืนยัน เพื่อไม่ให้หยิบไฟล์ผิดราย

| --- | --- |
| `apps/web/src/features/customers/CustomerDetail.tsx` | แสดงคลังไฟล์ของลูกค้าประจำ |
| `apps/web/src/features/assets/BrandAssetLibrary.tsx` | แสดงไฟล์ล่าสุดและประวัติในคลังลูกค้าหรือ JAZMINE |
| `apps/web/src/features/assets/AssetUpload.tsx` | ปุ่มแนบไฟล์ที่ใช้ร่วมกัน โดยไม่คัดลอกขั้นอัปโหลดหลายหน้า |
| `apps/web/src/features/assets/DraftAssetsPanel.tsx` | แบบตัวอย่างและสถานะไฟล์ที่ออเดอร์จะใช้ |
| `apps/web/src/features/orders/DraftEditor.tsx` | เลือกลูกค้าแล้วใช้แบรนด์ของลูกค้า; ลูกค้าขาจรใช้ JAZMINE |

| `apps/server/src/assets/asset-service.ts` | คัดไฟล์ตามเจ้าของ ตรวจสิทธิ์ และบันทึกประวัติในจุดเดียว |
| `apps/server/src/orders/draft-service.ts` และ `confirmation-service.ts` | กันร่างที่ระบุแบรนด์ไม่ตรงกับลูกค้าที่เลือก |
| `database/migrations/0025_reusable_brand_assets.sql` | ให้เก็บไฟล์กลางและไฟล์ลูกค้าได้โดยไม่ต้องสร้างร่างออเดอร์ก่อน |
