# รับออเดอร์และเตรียมใบผลิตแบบกดง่าย

## สิ่งที่ใช้ได้ในรอบนี้

1. เมื่อบันทึกร่างออเดอร์แล้ว หน้าจอแบ่งเป็น **1 ใบราคา → 2 ไฟล์ → 3 ยืนยัน** กดรูปและชื่อขั้นเพื่อสลับได้ตลอด รายการและราคายาว ๆ พับเก็บไว้ให้เปิดดูเมื่อต้องการ ปุ่มแก้ร่างยังอยู่ท้ายหน้าจอ การออกใบราคาและการยืนยันออเดอร์ยังเป็นคนละการกระทำ
2. เจ้าของ แอดมิน และกราฟิกอัปโหลดแบบตัวอย่าง ป้ายคอ หรือเทปคอแล้วไฟล์พร้อมใช้ทันที กราฟิกเปิดคลัง JAZMINE และคลังของลูกค้าประจำที่เลือกร่างอยู่ได้ ไฟล์เดิมที่เคยค้างตรวจยังมีช่องให้ผู้มีสิทธิ์จัดการ
3. ในหน้าเตรียมใบผลิต เลือกรายการและไซซ์ แล้ววางชื่อกับเบอร์หลายบรรทัดได้ หนึ่งบรรทัดต่อหนึ่งตัว คัดลอกสองคอลัมน์จากตารางได้ ระบบแสดงตัวอย่างก่อนเพิ่ม และเตือนเมื่อจำนวนเกินที่จัดผลิต รายชื่อเดิมยังแก้ทีละคนได้; ถ้ารายชื่อมากจะแสดงทีละ 40 คนเพื่อให้หน้าจอไม่หนัก

## สิ่งที่ยังต้องตรวจด้วยคน

- ตรวจราคา รายละเอียดสินค้า และแบบตัวอย่างก่อนออกใบราคา/ยืนยันจริง ระบบยังตรวจเงื่อนไขเดิมก่อนยืนยัน
- ถ้าแก้ร่างหลังแนบแบบตัวอย่าง ต้องส่งแบบตัวอย่างใหม่ให้ตรงกับร่างฉบับล่าสุด ป้ายคอและเทปคอของลูกค้าประจำเก็บไว้ใช้ซ้ำ
- การวางชื่อรับรูปแบบ `ชื่อ` หรือ `ชื่อ,เบอร์` หรือสองคอลัมน์คั่นด้วย Tab ไม่อ่านไฟล์ตารางโดยตรง และไม่ได้เดาไซซ์จากข้อความที่วาง ต้องเลือกไซซ์ก่อน
- ใบผลิตยังต้องให้ผู้มีสิทธิ์ตรวจและกดทำใบผลิตให้พร้อมหลังแนบไฟล์ชิ้นงานครบ

## ส่วนที่เปลี่ยนและผลกระทบ

| ส่วน | หน้าที่และผลกระทบ |
| --- | --- |
| `apps/web/src/features/orders/OrderDraftsPage.tsx`, `order-entry.css` | จัดลำดับ 3 ขั้นและหน้าสรุปย่อ ไม่เปลี่ยนสูตรราคาหรือการบันทึกออเดอร์ |

| `apps/server/src/assets/asset-service.ts`, `packages/contracts/src/assets.ts` | ตรวจสิทธิ์จากระบบจริง ผูกคลังกับลูกค้าที่เลือก ให้กราฟิกอัปโหลดแล้วพร้อมใช้ เก็บฉบับและประวัติไว้ |

| `apps/web/src/styles.css` | จัดกล่องวางรายชื่อและการแบ่งหน้ารายชื่อ |

## ผลตรวจ

ตรวจชนิดข้อมูล รูปแบบโค้ด และสร้างโปรแกรมผ่าน ทดสอบด้วยฐานแยกจากร้าน: สิทธิ์และคลังไฟล์, ออเดอร์หลายไซซ์, ของแถม, ใบเสนอราคา, การวางชื่อเกินจำนวน, การบันทึกชื่อและเบอร์ในใบผลิต, PDF และหน้าจอมือถือ 320/390 พิกเซลผ่าน

หากเอกสารเก่าบอกว่ากราฟิกต้องรอคนอนุมัติ ให้ใช้ข้อตกลงล่าสุดในหน้านี้ โดยกฎโครงการให้ยึด Phase 0 ถึง Phase 6 ตามลำดับ และ Phase 5 ใช้ `JAZMINE_PHASE_5_FINAL.md`
