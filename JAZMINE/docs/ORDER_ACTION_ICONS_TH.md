# ไอคอนช่วยกดงานออเดอร์

## วิธีดูปุ่ม

ปุ่มในทางเดินสร้างออเดอร์ เสนอราคา แนบไฟล์ ยืนยัน และเตรียมใบผลิต มีรูปเล็กอยู่หน้าคำสั่ง รูปเดียวกันใช้กับงานชนิดเดียวกัน เช่น **+** เพิ่มรายการ, รูปแผ่นตรวจใช้ตรวจข้อมูล, รูปแผ่นเอกสารใช้ออกใบเสนอราคา, รูปแผ่นบันทึกใช้บันทึก, และรูปเครื่องพิมพ์ใช้พิมพ์ ปุ่มสำคัญยังมีคำกำกับสั้น ๆ เพื่อให้กดถูกแม้ไม่คุ้นกับรูป

บนมือถือปุ่มยังมีพื้นที่กดอย่างน้อย 44 พิกเซล รูปไม่ย่อจนมองไม่เห็น โหมดมืดใช้สีปุ่มเดิมของระบบ ปุ่มที่ยังทำไม่ได้ยังแสดงเหตุผลตามขั้นงานเดิม

## สิ่งที่ตรวจจากระบบก่อนแก้

หน้าร่างออเดอร์ใช้ปุ่มจากหลายส่วน ได้แก่ เลือกสินค้าและไซซ์ บันทึกร่าง เสนอราคา ไฟล์ และยืนยันออเดอร์ ใบผลิตเป็นอีกส่วนหนึ่ง การเพิ่มรูปปุ่มครั้งนี้เปลี่ยนเฉพาะหน้าตาและคำอธิบายที่มองเห็น ไม่เปลี่ยนราคา สิทธิ์ จำนวน ช่วงรอตรวจไฟล์ หรือขั้นออกใบผลิต

## หน้าที่ไฟล์

| ส่วน | หน้าที่ |
| --- | --- |
| `apps/web/src/components/ActionButton.tsx` | กำหนดความหมายของรูปปุ่มในที่เดียว ทุกหน้าเรียกใช้ชื่อการกระทำเดียวกัน |
| `apps/web/src/features/orders/` | แสดงรูปที่ปุ่มสร้างร่าง เพิ่มไซซ์ ตรวจราคา บันทึก และยืนยันออเดอร์ |
| `apps/web/src/features/quotations/` | แสดงรูปที่ปุ่มตรวจ ออก ค้น เปิด และพิมพ์ใบเสนอราคา |
| `apps/web/src/features/assets/` | แสดงรูปที่ปุ่มแนบ ตรวจ และเปิดไฟล์งาน |
| `apps/web/src/features/production/` | แสดงรูปที่ปุ่มบันทึกใบผลิต แนบชิ้นงาน และทำใบผลิตให้พร้อม |
| `apps/web/src/styles.css` | ดูแลขนาดรูปและตำแหน่งบนปุ่มทั้งจอคอมและมือถือ |

## งานหน้าจอที่ยังอยู่ในแผนเดิม

การแบ่งหน้ารับออเดอร์เป็นขั้นสั้น ๆ การให้กราฟิกอัปโหลดไฟล์แล้วพร้อมใช้ทันที และช่องวางชื่อกับเบอร์เสื้อหลายบรรทัด เป็นงานถัดไปตามแผนที่คุยกัน รอบนี้ทำรูปปุ่มก่อนเพื่อให้เห็นและกดงานหลักได้เร็วขึ้น
