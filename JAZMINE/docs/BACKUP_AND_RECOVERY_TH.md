# สำรองข้อมูลและทดลองกู้คืน — คู่มือเจ้าของ JAZMINE

ขั้นแรกของ W10 เพิ่มเมนู **Backup & recovery** ให้เจ้าของแล้ว ใช้กับรุ่นทดลองที่เก็บข้อมูลในเครื่อง การกู้คืนสร้างข้อมูลอีกชุดให้เปิดตรวจได้ก่อน ข้อมูลร้านชุดเดิมยังอยู่ในที่เดิม

## สำรองข้อมูลตามปกติ

1. เปิด JAZMINE และเข้าสู่ระบบด้วยบัญชีเจ้าของ
2. เปิดเมนู **Backup & recovery**
3. ตั้งรหัสไฟล์สำรอง 12–128 ตัวอักษร กรอกซ้ำและใส่เหตุผล เช่น “สำรองหลังจบงานประจำวัน” รหัสนี้แยกจากรหัสเข้าสู่ระบบ
4. กด **Download backup** รอให้เสร็จ แล้วตรวจว่ามีไฟล์ `JAZMINE_BACKUP_วันเวลา_รหัส.jazbackup` ใน Downloads หรือที่ที่เลือกบันทึก
5. เก็บสำเนาไฟล์ไว้อีกอุปกรณ์หนึ่ง และเก็บรหัสให้หาเจอเมื่อจำเป็น รหัสที่ลืมไม่สามารถขอคืนจากระบบได้

ทำผ่านเมนูได้ระหว่างโปรแกรมเปิดอยู่ ระบบรอรายการที่กำลังบันทึกให้จบก่อนสร้างสำเนา ไม่ต้องคัดลอกโฟลเดอร์ฐานข้อมูลเอง ประวัติ “Backup created” บอกว่าระบบสร้างไฟล์แล้ว เจ้าของยังต้องตรวจว่าเบราว์เซอร์บันทึกไฟล์ลงเครื่องเรียบร้อย

รวมข้อมูลบัญชี ลูกค้า สินค้า ราคา ออเดอร์ เงิน การส่ง งานผลิต ประวัติ และไฟล์ที่แนบเก็บในระบบ เช่น รูปสินค้า ไฟล์กราฟิกและชิ้นงาน ข้อมูลใบแจ้งหนี้และใบผลิตแต่ละฉบับอยู่ด้วย จึงเปิดพิมพ์ใหม่ได้

ไฟล์นอกระบบ เช่น PDF ที่ดาวน์โหลดไว้เอง ไฟล์งานใน Downloads โปรแกรม JAZMINE เครื่องมือติดตั้ง และการตั้งค่าเครื่องใน `.env` ไม่อยู่ในไฟล์สำรอง ต้องเก็บแยก ควรเก็บตัวโปรแกรมรุ่นที่ใช้สำรองและ `pnpm-lock.yaml` ไว้ด้วย เพื่อกู้คืนด้วยรุ่นที่ตรงกัน

## ทดลองกู้คืนและตรวจข้อมูล

1. ในหน้าเดียวกัน ส่วน **Restore a separate copy** เลือกไฟล์ `.jazbackup`
2. ใส่รหัสของไฟล์นั้นและเหตุผล แล้วกด **Verify and restore copy**
3. รอข้อความ **Recovery copy verified** ระบบตรวจข้อมูลทุกตารางและเนื้อหาไฟล์กับตอนสำรอง ก่อนเตรียมสำเนาให้เปิดตรวจ
4. กด **Copy folder path** เปิด File Explorer แล้ววางตำแหน่งนั้นในช่องที่อยู่
5. เปิด `START_RECOVERED_JAZMINE.cmd` ภายในโฟลเดอร์สำเนา รอจนโปรแกรมพร้อม แล้วเข้า `http://localhost:5176`
6. เข้าด้วยชื่อผู้ใช้และรหัสผ่านที่มีอยู่ **ณ วันสำรอง** หน้าจอมีแถบ **Recovery workspace** ให้แยกจากชุดเดิมได้
7. ตรวจออเดอร์ล่าสุดที่ควรมี ยอดรับเงิน/คืนเงิน/ค้างเงิน จำนวนผลิต/พร้อมส่ง/ส่งแล้ว และเปิดไฟล์แนบตัวอย่าง ก่อนตัดสินใจนำชุดนี้ไปทำงานต่อ
8. ปิดโปรแกรมสำเนาด้วย `Ctrl+C` เมื่อจบการตรวจ

ค่าเริ่มต้นเก็บสำเนาใต้ `local-data/recovery/JAZMINE_RECOVERY_รหัส/` แต่ละรอบมีโฟลเดอร์ใหม่และรายงานของตัวเอง เปิดผลรอบก่อนจากประวัติ 20 รายการล่าสุดได้ รายงานเป็นผลตรวจเมื่อสร้างสำเนา ไม่ใช่การตรวจสุขภาพของโฟลเดอร์ซ้ำทุกครั้งที่เปิดรายงาน

หากการเชื่อมต่อขาดหลังส่งคำขอ ให้ใช้ **Retry recovery** ของรายการเดิม ระบบคืนผลเดิมเมื่อสำเร็จแล้ว ไม่สร้างสำเนาซ้ำ การเปิดหน้าใหม่แล้วเริ่มคำขอใหม่ถือเป็นการตรวจอีกครั้ง

สำเนามีข้อมูลถึงวันเวลาสำรอง งานที่เกิดภายหลังยังอยู่ในชุดเดิมและไม่ได้รวมเข้าชุดสำเนาอัตโนมัติ การเปิดสำเนาไม่เปลี่ยน `START_JAZMINE.cmd` ให้ชี้มาที่สำเนา เจ้าของควรเลือกให้ชัดเจนว่าจะใช้ชุดใดต่อ และวางแผนย้ายงานหลังวันสำรองก่อนใช้จริง

สำเนาบังคับให้ทุกคนเข้าสู่ระบบใหม่ และปิดลิงก์ติดตามลูกค้าที่ติดมาจากไฟล์สำรอง เจ้าของ/ADMIN ต้องออกลิงก์ใหม่เมื่อเลือกใช้สำเนานี้ การเข้าสู่ระบบและลิงก์ของข้อมูลชุดเดิมยังทำงานตามเดิม การเข้าโปรแกรมสำเนาแยกจากโปรแกรมปกติ แม้เปิดด้วยเบราว์เซอร์เดียวกัน

สำเนากู้คืนไม่เริ่มงานเบื้องหลังหรือนำเข้าสินค้าและราคาตั้งต้นซ้ำเอง ใช้ตรวจข้อมูลก่อน ส่วนการเลือกเป็นระบบหลักและเปิดบริการจริงยังต้องเตรียมแยก

## ถ้าโปรแกรมเดิมเปิดไม่ได้

1. เปิด `START_RECOVERY_TOOL.cmd` ในโฟลเดอร์ JAZMINE
2. รอโปรแกรมพร้อม แล้วเข้า `http://localhost:5176` เครื่องมือนี้ใช้ข้อมูลว่างแยกต่างหาก ไม่ต้องเปิดฐานข้อมูลเดิม
3. ตั้งบัญชีเจ้าของชั่วคราวสำหรับเครื่องมือ แล้วเข้า **Backup & recovery** เลือกไฟล์สำรองและทำตามขั้นตอนกู้คืนด้านบน
4. จดหรือคัดลอกตำแหน่งสำเนา แล้วปิดเครื่องมือด้วย `Ctrl+C` ก่อน เพราะเครื่องมือและสำเนาใช้ช่องเปิดเดียวกัน
5. เปิด `START_RECOVERED_JAZMINE.cmd` ในโฟลเดอร์สำเนา เข้าด้วยบัญชีในไฟล์สำรอง ไม่ใช่บัญชีชั่วคราวของเครื่องมือ

เครื่องมือแต่ละรอบสร้าง `local-data/RECOVERY_TOOL_รหัส` ใหม่ ไม่มีรหัสเจ้าของร่วมกัน และไม่ลบโฟลเดอร์เก่าเอง หากไม่มีไฟล์สำรองที่ใช้ได้ เครื่องมือนี้ไม่ได้ทำให้ข้อมูลที่เสียกลับมาเอง

## เมื่อมีข้อความขัดข้อง

| ข้อความหรืออาการ                   | สิ่งที่ควรทำ                                                                                          |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------- |
| รหัสไม่ถูกหรือไฟล์ใช้ไม่ได้        | ตรวจไฟล์และรหัสของไฟล์นั้น หากยังไม่ได้ให้ลองไฟล์สำรองอีกชุด ข้อมูลเดิมไม่ถูกทับ                      |
| รุ่นโปรแกรมไม่ตรงกับไฟล์           | ให้ผู้ดูแลใช้โปรแกรมรุ่นที่ตรงกัน ไม่เปลี่ยนชื่อไฟล์เพื่อฝืนเปิด                                      |
| โปรแกรมหรือช่องเปิดถูกใช้อยู่      | ปิดหน้าต่างชุดที่ใช้ตำแหน่งหรือช่องเปิดเดียวกันก่อน                                                   |
| ฐานข้อมูลเปิดอยู่หรือปิดไม่สมบูรณ์ | ปิดโปรแกรมเดิมให้ครบ หากยังไม่ได้ให้ผู้ดูแลตรวจ หรือใช้เครื่องมือกับไฟล์สำรอง อย่าลบโฟลเดอร์ฐานข้อมูล |
| มีสำเนากู้คืน 10 ชุดแล้ว           | ให้ผู้ดูแลตรวจและย้ายเก็บชุดเก่าที่ปิดแล้วก่อน ระบบไม่ลบสำเนาให้เอง                                   |

ตัวกันเปิดฐานซ้ำใช้ไฟล์ลงท้าย `.jazmine-owner` หากไฟดับหรือถูกบังคับปิด ไฟล์นี้อาจค้าง ระบบไม่ยึดสิทธิ์ฐานเอง ผู้ดูแลต้องตรวจว่าทุกโปรแกรมที่ใช้ฐานนั้นหยุดจริงก่อนจัดการไฟล์นี้ ไม่ควรลบเพื่อข้ามข้อความเตือนระหว่างมีโปรแกรมเปิดอยู่

## ขอบเขตของขั้นนี้และงานที่ยังเหลือ

- เฉพาะเจ้าของที่สร้าง/กู้คืน/ดูประวัติได้ พนักงาน ADMIN และฝ่ายอื่นเข้าไม่ได้
- รองรับไฟล์สำรองไม่เกิน 64 MiB และข้อมูลหลังคลายไฟล์ไม่เกิน 256 MiB จำกัดสำเนากู้คืน 10 ชุดต่อโฟลเดอร์ ยังไม่ได้รับรองกับฐานขนาดใหญ่
- ตอนนี้เจ้าของกดสำรองเอง ยังไม่มีการสำรองอัตโนมัติ สำเนานอกเครื่องอัตโนมัติ หรือการย้อนข้อมูลถึงเวลาระหว่างวัน
- การสำรองฐานข้อมูลภายนอกและไฟล์บนบริการออนไลน์ต้องทำอีกชุด เป้าหมาย Phase 6 ที่ยอมสูญงานได้ไม่เกิน 15 นาทีและกลับมาใช้ได้ใน 4 ชั่วโมง **ยังไม่ได้รับรองจากงานรอบนี้**
- W10 ยังเหลือการตรวจข้อมูลจำนวนมาก ผู้ใช้หลายคนทำงานจริง แผนเปิดใช้/ย้อนกลับ และงานค้าง W4–W9 รวมถึงต้นทุนก่อนรายงานกำไร
