## เปิดใช้อย่างไร

หยุดโปรแกรมเดิมด้วย Ctrl+C แล้วเปิด START_JAZMINE.cmd ตารางจะนำเข้าอัตโนมัติครั้งเดียวเมื่อมีบัญชีเจ้าของ ไม่มีการเพิ่มซ้ำหรือเขียนทับราคาฉบับที่เจ้าของแก้แล้ว จากนั้นเปิดเมนู “ราคาและส่วนลด”

- เจ้าของแก้ตารางและส่วนเพิ่มไซซ์/ผ้าได้ ต้องใส่เหตุผล ทุกครั้งสร้างราคาฉบับใหม่ เก็บฉบับเดิมไว้
- แอดมินอ่านราคาและทดลองคำนวณส่วนลดได้ แต่เปลี่ยนตารางราคาไม่ได้
- ผ้าว่างหมายถึงยังไม่ทราบราคาเพิ่ม ไม่ใช่ราคา 0 ใส่ 0 ได้เมื่อเจ้าของยืนยันว่าไม่คิดเพิ่ม
- ตัวทดลองใช้เฉพาะไซซ์และผ้าที่กำหนดให้เสื้อนั้นแล้ว ผ้าที่ปิดใช้งานเลือกไม่ได้
- ลดเปอร์เซ็นต์ก่อนลดเงิน ยอดต่ำสุด 0 ของแถมไม่คิดราคาแต่รวมในจำนวนที่ต้องทำ
- คำนวณเงินกีบเป็นจำนวนเต็ม ใช้เลขจำนวนเต็มความแม่นยำสูงสำหรับส่วนลด แล้วปัดครึ่งขึ้นที่ขอบเขตยอดเงินเป็น 1 กีบ ไม่ปัดหลักพัน

## ขอบเขตที่ยังต้องทำต่อ

หน้านี้เป็นตัวทดลองเฉพาะตัวเสื้อและผ้า ไม่ใช่ยอดออเดอร์สุดท้าย ยังไม่รวมราคาเพิ่มแขน บ่า ปลายแขน ส่วนผ้าของแต่ละชิ้น กติกาซื้อ X แถม Y อัตโนมัติ อัตราแลกเปลี่ยน THB/USD และเอกสารออเดอร์จริง ไม่มีการตั้งตัวเลขต้นทุนหรือกำไร ราคาส่วนที่ยังไม่ระบุจะไม่ถูกเติมจากตัวอย่าง เมื่อสร้างออเดอร์จริงต้องเก็บราคาฉบับและค่าต่าง ๆ ตอนยืนยันด้วย
