# งานเบื้องหลัง

ส่วนนี้จะทำงานที่ไม่จำเป็นต้องให้ผู้ใช้รออยู่หน้าจอ เช่น เตรียม PDF แจ้งเตือน และลองทำงานที่ล้มเหลวอีกครั้ง

เริ่มทำหลังข้อมูลธุรกิจถูกบันทึกสำเร็จแล้ว การเตรียม PDF ไม่สำเร็จต้องไม่สร้างออเดอร์หรือเลขเอกสารใหม่ซ้ำ

ใช้กฎจากส่วนหลังบ้านผ่านขอบเขตที่กำหนด ไม่เขียนสูตรราคาและกฎธุรกิจชุดที่สอง

รุ่นนี้รับเหตุการณ์ผู้ใช้พื้นฐาน และเตรียม/เก็บ PDF ของใบเสนอราคา ใบแจ้งหนี้ ใบรับเงิน และ PS แต่ละฉบับแล้ว ใช้งานจากข้อมูลที่บันทึกจริง ลองใหม่เลขเดิม และรับช่วงงานที่หยุดกลางทางได้ งานแจ้งเตือนยังเป็นขั้นต่อไป โหมดฐานฝังทำงานร่วมกับ API; ใช้ `pnpm worker` แยกเมื่อเชื่อม PostgreSQL ภายนอกเท่านั้น สำเนากู้คืนไม่รันอัตโนมัติ ดูคู่มือภาษาไทย [เก็บ PDF](../../docs/STORED_PDFS_TH.md)
