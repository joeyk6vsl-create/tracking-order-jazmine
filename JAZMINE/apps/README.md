# โปรแกรมหลักของ JAZMINE

| โฟลเดอร์ | ใช้ทำอะไร                                               |
| -------- | ------------------------------------------------------- |
| `web`    | หน้าจอที่เจ้าของ พนักงาน และลูกค้าใช้งานผ่านเบราว์เซอร์ |
| `server` | ตรวจสิทธิ์ ตรวจข้อมูล คำนวณ และบันทึกรายการ             |
| `worker` | ทำงานที่รอประมวลผล เช่น เตรียมเอกสารและส่งการแจ้งเตือน  |

ทั้งสามอยู่ในโครงการเดียวกันตามแผน Modular Monolith เดิม การแยกโฟลเดอร์ช่วยแยกหน้าที่ ไม่ได้หมายถึงต้องแยกระบบบริการหลายชุด

ขณะนี้มีเว็บและหลังบ้านสำหรับผู้ใช้/สิทธิ์ พร้อม worker รับเหตุการณ์พื้นฐานแล้ว ดูวิธีเปิดที่ `../HOW_TO_RUN_TH.md` ส่วนออเดอร์และเงินยังไม่ได้สร้าง
