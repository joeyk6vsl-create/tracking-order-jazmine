# ส่วนหลังบ้านสำหรับตรวจและบันทึกข้อมูล

เพิ่ม `src/documents` สำหรับเก็บข้อมูลใบแต่ละฉบับ ส่งทำ PDF เบื้องหลัง ตรวจสิทธิ์ และดาวน์โหลดไฟล์เดิม ใช้กฎราคา/ออเดอร์/เงิน/การผลิตจากส่วนเจ้าของเดิม ไม่คำนวณซ้ำในตัวสร้างเอกสาร ดู [คู่มือเก็บ PDF ภาษาไทย](../../docs/STORED_PDFS_TH.md)

หน้าที่คือรับคำขอจากหน้าจอ ตรวจตัวตน สิทธิ์ และกฎธุรกิจ แล้วจึงอ่านหรือบันทึกข้อมูล

ตัวอย่างงาน: เข้าสู่ระบบ ยืนยันออเดอร์ คำนวณราคา รับเงิน แก้รายการผิด และยืนยันการส่งสินค้า

จะใช้ NestJS/Fastify ตาม Phase 6 แต่ละเรื่องมีเจ้าของชัดเจน เช่น `auth`, `user`, `customer`, `pricing`, `order`, `production`, `payment`, `shipment`, `tracking`, `inventory`, `analytics` และ `settings` รวมถึงส่วนร่วมตามแผน

ภายในแต่ละเรื่องจะแยกกฎ งานดำเนินการ ที่เก็บข้อมูล และจุดรับคำขอ ตามโครงสร้าง `domain`, `application`, `infrastructure`, `http` ในเอกสารเดิม ห้ามรวมทุกเรื่องเป็นไฟล์ใหญ่ไฟล์เดียว

ขณะนี้มีระบบบัญชีและสิทธิ์จริงใน `src/identity` และจุดรับคำขอใน `src/app.ts` งานรหัสผ่านเรียกผ่านคำสั่งของ AUTH ภายในรายการเปลี่ยนข้อมูลเดียวกับ USER
