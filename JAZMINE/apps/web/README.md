# หน้าจอสำหรับผู้ใช้งาน

ส่วนนี้จะเก็บหน้าจอเข้าสู่ระบบ ลูกค้า ออเดอร์ การผลิต รับเงิน ส่งสินค้า และติดตามงาน

เมื่อเริ่มโปรแกรม จะใช้ React/Vite ตามแผนเดิม โดยจัดงานตามเรื่อง เช่น `auth`, `customers`, `orders` และ `production` ภายใต้โฟลเดอร์งานของส่วนหน้าจอ

แนวทางแยกไฟล์:

- หน้าหลักของงานมีชื่อบอกหน้าที่ เช่น `OrderCreatePage.tsx`
- ส่วนย่อย เช่น ปุ่มรูปสินค้าและยอดสรุป แยกไฟล์เพื่อใช้ซ้ำ
- หน้าจอแสดงราคาและสิทธิ์ที่ระบบตรวจแล้ว ไม่ตัดสินรายการเงินจริงด้วยตัวเอง
- การเลือกขาจรไม่ต้องเพิ่มรายชื่อลูกค้าประจำ
- ชุดแบบร่างเดิมเป็นภาพจำลองสำหรับตรวจ ยังไม่ใช่โปรแกรมในโฟลเดอร์นี้

ขณะนี้มีหน้าสร้างเจ้าของ เข้าสู่ระบบ เปลี่ยนรหัส หน้าหลัก และจัดการพนักงานจริงใน `src` เปิดด้วยคำสั่งโครงการหลัก ดูรายชื่อไฟล์ที่ `../../FILE_GUIDE_TH.md`
