# วิธีเปิดและทดลอง JAZMINE

เพิ่มแล้ว: ปิด–เปิด `START_JAZMINE.cmd` ใหม่ → เปิดเอกสาร → เลือก **Download current-status copy** เพื่อได้สำเนาพร้อมสถานะที่ตรวจใหม่ ส่วนเจ้าของเปิด **Payments & delivery → Automatic archive → Owner archive settings** เพื่อตั้งค่าเก็บเก่าอัตโนมัติได้ ค่าเริ่มต้นปิดไว้ อ่าน [เงื่อนไขและวิธีใช้ภาษาไทย](docs/DOCUMENT_STATUS_AND_AUTO_ARCHIVE_TH.md)

เพิ่มแล้ว: ปิด–เปิด `START_JAZMINE.cmd` ใหม่ → เจ้าของ/ADMIN เปิด **เตรียมใบผลิต** → เลือกออเดอร์ → **Review previous production** → เปิดประวัติแผน → **Check plan reversal** → ตรวจทุกใบ ใส่เหตุผล ยืนยันว่าไม่มีงาน/ส่งเพิ่ม → **Reverse entire reuse plan** อ่าน [คู่มือและเงื่อนไขก่อนลอง](docs/REVERSE_PRODUCTION_REUSE_PLAN_TH.md) แผนเก่าที่ไม่มีข้อมูลสถานะก่อนปิดยังต้องตรวจด้วยคน

เพิ่มแล้ว: ปิด–เปิด `START_JAZMINE.cmd` ใหม่ → เข้าบัญชีเจ้าของ → **QR ຮັບເງິນ / Shop payment QR** → ตั้งค่า LAK และ THB แยกกันจากรูปจริงของธนาคาร เจ้าของต้องตรวจภาพตัวอย่างผ่านแอปธนาคารก่อนเปิดใช้ แอดมินเปิดใบแจ้งหนี้แล้วเลือก **Include bank payment QR** และ **Check and attach payment QR** ได้ ดู [คู่มือพร้อมข้อจำกัดภาษาไทย](docs/PAYMENT_QR_TH.md) ยังไม่มีบัญชีหรือ QR จริงถูกใส่แทนร้าน

เพิ่มแล้ว: เปิดใบเสนอราคา ใบแจ้งหนี้ ใบรับเงิน หรือหน้า A4 ใบผลิต แล้วดู **Stored original PDF** เมื่อขึ้น **Original PDF stored** กด **Download stored PDF** ได้ ถ้ายังไม่สำเร็จ ใช้ Retry พร้อมเหตุผลเพื่อทำไฟล์เลขเดิม ดู [คู่มือเก็บ PDF ภาษาไทย](docs/STORED_PDFS_TH.md) ให้ปิด–เปิด `START_JAZMINE.cmd` ใหม่ก่อนลอง ไม่ต้องล้างข้อมูล

เพิ่มแล้ว: **ร่างออเดอร์ → เปิดร่างที่บันทึก → Quotation → Check quotation → ใส่เหตุผล → Issue quotation** แล้วเปิดใบเพื่อพิมพ์ PDF ได้ ค้นใบเก่าจากเมนู **Quotations** QR ใช้สำหรับพนักงานที่เข้าสู่ระบบ ดู [คู่มือใบเสนอราคาภาษาไทย](docs/QUOTATIONS_TH.md) ให้หยุด–เปิด `START_JAZMINE.cmd` ใหม่และรีเฟรชก่อนลอง ไม่ต้องล้างข้อมูลเดิม

เพิ่มแล้ว: เปิดใบแจ้งหนี้ใน **ออเดอร์ที่ยืนยันแล้ว → เลือกออเดอร์** ติ๊ก **Include customer tracking QR** วางลิงก์เดิมแล้วกด **Validate and attach QR** หรือเปิด **Create or replace link** เพื่อสร้าง จากนั้นใช้ปุ่มพิมพ์ของระบบ ดู [คู่มือ QR ภาษาไทย](docs/INVOICE_TRACKING_QR_TH.md) ให้ปิด–เปิด `START_JAZMINE.cmd` ใหม่และรีเฟรชก่อนลอง QR สำหรับลูกค้าต้องใช้ที่อยู่เว็บที่ลูกค้าเปิดถึง ไม่ใช่ localhost ของเครื่องร้าน

เพิ่มแล้ว: ใน **ร่างออเดอร์ → เปิดแก้รายการ** ใช้ **Make gift-only** หรือใส่จำนวนซื้อ 0 และแถมมากกว่า 0 ได้ ระบบยังนับจำนวนผลิต/ส่งให้ครบ ดู [คู่มือของแถมล้วนภาษาไทย](docs/GIFT_ONLY_LINES_TH.md) ถ้าโปรแกรมยังเปิดรุ่นก่อน ให้หยุดด้วย Ctrl+C เปิด `START_JAZMINE.cmd` ใหม่ แล้วรีเฟรชหน้าเว็บ

เพิ่มแล้ว: เปิด **Payments & delivery → เลือกออเดอร์ → Cancellation & archive → Review order effects** เพื่อยกเลิกพร้อมเหตุผล เจ้าของกำหนดยอดสุดท้ายและเก็บออเดอร์ที่เคลียร์แล้วได้ เปิดข้อมูลเก่าด้วย **Include archived orders** ดู [คู่มือยกเลิกและเก็บข้อมูลเก่าภาษาไทย](docs/CANCEL_AND_ARCHIVE_ORDERS_TH.md) ให้หยุดโปรแกรมด้วย Ctrl+C เปิด `START_JAZMINE.cmd` ใหม่ และรีเฟรชหน้าเว็บก่อนลอง ไม่ต้องล้างข้อมูล

เพิ่มแล้ว: เจ้าของ/ADMIN เปิดคิวงานผลิต → ใบต้นทาง → ปัญหา Resolved → **Correct recorded quantities** เพื่อแก้จำนวนพร้อมเหตุผลและประวัติเดิม ดู [คู่มือแก้จำนวนภาษาไทย](docs/CORRECT_PRODUCTION_ISSUE_QUANTITIES_TH.md) ถ้าเปิดรุ่นก่อนอยู่ ให้หยุดด้วย Ctrl+C เปิด `START_JAZMINE.cmd` ใหม่ แล้วรีเฟรชหน้าเว็บ ไม่ต้องล้างข้อมูล

เพิ่มแล้ว: หลังแก้ออเดอร์เป็นฉบับใหม่ เจ้าของ/ADMIN เปิด **เตรียมใบผลิต → Review previous production** เพื่อเลือกจำนวนใช้ต่อ จากนั้น GRAPHIC/เจ้าของตรวจร่างและทำใบใหม่ให้พร้อมก่อนฝ่ายผลิตทำต่อ ดู [คู่มือภาษาไทย](docs/CONTINUE_PRODUCTION_AFTER_ORDER_EDIT_TH.md) ปิด–เปิดโปรแกรมใหม่เพื่อเพิ่มโครงสร้างข้อมูลและใช้ส่วนที่ปรับแล้ว ไม่ต้องล้างข้อมูลเดิม

W10 ตรวจข้อมูลมากและหลายการเข้าสู่ระบบพร้อมกันแล้ว ปรับรายงานให้ลดการคำนวณซ้ำ เจ้าของใช้หน้ารายงานตามเดิม ดู [ผลตรวจภาษาไทย](docs/VOLUME_AND_CONCURRENT_USE_TH.md) ปิด–เปิดโปรแกรมใหม่เพื่อใช้ส่วนหลังบ้านที่ปรับแล้ว ข้อมูลของร้านยังอยู่ตามเดิม

W10 เริ่มแล้ว: เจ้าของมีเมนู **Backup & recovery** สำหรับไฟล์สำรองที่มีรหัสผ่านและทดลองกู้คืนเป็นข้อมูลอีกชุด ถ้าโปรแกรมเดิมเปิดไม่ได้ มี `START_RECOVERY_TOOL.cmd` ดู [คู่มือสำรองและกู้คืนภาษาไทย](docs/BACKUP_AND_RECOVERY_TH.md) ยังไม่มีการสำรองอัตโนมัติ

W9 เพิ่มแล้ว: เจ้าของมีเมนู Reports, เจ้าของ/ADMIN มี Customer requests และผู้ใช้มี Search ตามสิทธิ์ สร้างลิงก์ลูกค้า/QR ได้ใน Payments & delivery ดูขั้นตอนที่ `docs/TRACKING_REPORTS_SEARCH_TH.md` ลิงก์ในเครื่องยังไม่ใช่เว็บที่ลูกค้าภายนอกเปิดใช้ได้

งานรับเงินและส่งสินค้าเพิ่มแล้ว: หลังปิด–เปิดโปรแกรมตามวิธีด้านล่าง เจ้าของ/ADMIN เปิดเมนู **Payments & delivery** ดูขั้นตอนรับมัดจำ แก้ยอด คืนเงิน และส่งบางส่วนที่ `docs/PAYMENTS_AND_DELIVERY_TH.md` การคืนเงินให้เฉพาะเจ้าของ

## เปิดครั้งแรกบน Windows

1. เปิดโฟลเดอร์ `JAZMINE`
2. ดับเบิลคลิก `START_JAZMINE.cmd`
3. เก็บหน้าต่างโปรแกรมไว้ รอข้อความว่า API และหน้าจอพร้อม
4. เปิดเบราว์เซอร์ที่ `http://localhost:5173`
5. ถ้ายังไม่เคยตั้งค่า จะเห็นหน้าสร้างบัญชีเจ้าของ ให้กรอกชื่อที่แสดง ชื่อผู้ใช้ และรหัสผ่านที่ต้องการใช้
6. รหัสผ่านต้องอย่างน้อย 12 ตัวอักษร จดเก็บเองในที่ปลอดภัย ระบบไม่มีรหัสเริ่มต้นร่วมกัน

ข้อมูลฐานทดลองของคุณเริ่มว่าง ไม่มีบัญชีทดสอบหรือรหัสที่สร้างไว้ล่วงหน้า การสร้างเจ้าของครั้งแรกเปิดได้เฉพาะโหมดพัฒนาในเครื่อง และทำได้ครั้งเดียวเมื่อยังไม่มีผู้ใช้

## ทดลองเพิ่มพนักงาน

1. เข้าด้วยบัญชีเจ้าของ
2. เปิดเมนูพนักงาน หรือปุ่มจัดการทีมงาน
3. กดเพิ่มพนักงาน ใส่ชื่อผู้ใช้ ชื่อที่แสดง ระดับ `STAFF` และแผนก
4. กำหนดรหัสผ่านชั่วคราวอย่างน้อย 12 ตัวอักษร และส่งให้พนักงานด้วยช่องทางที่เหมาะสม
5. ออกจากระบบ แล้วทดลองเข้าด้วยบัญชีพนักงาน
6. พนักงานต้องเปลี่ยนรหัสชั่วคราวก่อนทำงาน หลังเปลี่ยนต้องเข้าสู่ระบบอีกครั้ง

พนักงานไม่เห็นเมนูจัดการผู้ใช้ เจ้าของแก้แผนก ปิดบัญชี และรีเซ็ตรหัสชั่วคราวได้ การเปลี่ยนสิทธิ์จะยกเลิกการเข้าสู่ระบบเดิมของบัญชีนั้นทุกอุปกรณ์

## ปิดและเปิดใหม่

กด `Ctrl+C` ในหน้าต่างที่เปิดโปรแกรมไว้ จากนั้นเปิดใหม่ด้วย `START_JAZMINE.cmd` ข้อมูลที่ยืนยันบันทึกแล้วอยู่ใน `local-data/postgres` ภายใต้โฟลเดอร์โครงการ

ฐานข้อมูลฝังนี้ต้องมีโปรแกรมเจ้าของฐานข้อมูลเพียงหนึ่งตัว ไม่เปิด JAZMINE สองชุดกับข้อมูลโฟลเดอร์เดียวกัน ระบบจะเตือนเมื่อเปิดซ้ำ ใช้เมนู **Backup & recovery** เพื่อสำรองระหว่างโปรแกรมเปิดอยู่ ไม่คัดลอกไฟล์ฐานข้อมูลเองขณะใช้งาน รอให้โปรแกรมหยุดเรียบร้อยหลัง Ctrl+C ก่อนเปิดใหม่

## ส่วนที่ทำงานได้ในรุ่นนี้

- สินค้า/รูป/ผ้า/ส่วนประกอบ ราคา ส่วนลด ของแถม และอัตราแลกเปลี่ยนที่เจ้าของตั้ง
- ร่างหลายรายการ ลูกค้าขาจร ยืนยันเลขออเดอร์/ใบแจ้งหนี้ และประวัติแต่ละฉบับ
- ไฟล์กราฟิกและอนุมัติ ใบผลิต A4/PDF งานหกแผนก ปัญหา ของเสีย งานทดแทน และพร้อมส่ง
- รับมัดจำ รับเพิ่ม แก้รายการผิด คืนเงินเฉพาะเจ้าของ ใบรับเงิน และส่งบางส่วน/ค้างเงิน/เลขติดตาม

- เจ้าของและพนักงาน ADMIN เพิ่ม ค้นหา และแก้ลูกค้าประจำได้
- กลุ่มราคาและแบรนด์ผลิตเก็บแยกกัน
- เบอร์ซ้ำแจ้งเตือนแต่ยังบันทึกได้
- เจ้าของปิดใช้งานหรือเปิดรายชื่อลูกค้ากลับได้ โดยไม่ลบประวัติ
- แบ่งหน้าครั้งละ 25 รายการ ค้นจากขึ้นต้นชื่อหรือเบอร์

- สร้างบัญชีเจ้าของครั้งแรก
- เข้าสู่ระบบ ออกจากระบบ และเปลี่ยนรหัสผ่าน
- เจ้าของเพิ่มบัญชี แก้ชื่อ ระดับ แผนก และสถานะพนักงาน
- ตั้งรหัสชั่วคราวใหม่พร้อมเหตุผล
- ตรวจสิทธิ์จากหลังบ้านและป้องกันเจ้าของคนสุดท้าย
- เก็บประวัติการเปลี่ยนบัญชีและเหตุผล
- หน้าหลักแสดงข้อมูลบัญชีจริงตามสิทธิ์

## ส่วนที่จะทำต่อ

หน้าติดตามลูกค้า รายงานรุ่นแรก ค้นหารวม สำรอง/ทดลองกู้คืน และการตรวจข้อมูลมาก/คำขอพร้อมกันในเครื่องเพิ่มแล้ว การใช้ต่องานหลังแก้ออเดอร์เพิ่มแล้ว งานถัดไปตรวจการแก้จำนวนปัญหาที่ปิดผิด จากนั้นทดลองรายแผนก อุปกรณ์/เครือข่ายจริง สำรองอัตโนมัตินอกเครื่องและแผนเปิดใช้งาน กำไรยังรอต้นทุนจริง

ไฟล์แบรนด์มีการแนบและอนุมัติแล้ว ต้องตรวจความพร้อมตามออเดอร์แต่ละฉบับ การโอนงานผลิตที่ยังไม่ส่งข้ามฉบับและการรับสินค้าคืนจริงยังไม่อัตโนมัติ

## เปิดรุ่นใหม่หลังอัปเดตโค้ด

หยุดหน้าต่างโปรแกรมเดิมด้วย Ctrl+C แล้วเปิด `START_JAZMINE.cmd` ใหม่ การเปิดในโหมดพัฒนาจะเพิ่มโครงสร้างข้อมูลที่ยังไม่มีให้เอง บัญชีและข้อมูลเดิมยังอยู่ ใช้ชื่อผู้ใช้และรหัสผ่านเดิมได้ ไม่ต้องล้าง `local-data`

หน้าตามีสีและรายละเอียดเพิ่มจากแบบร่าง ใช้ภาษา Lao ผสมข้อความอธิบายภาษาไทยบางจุดในรุ่นเริ่มต้น รองรับมือถือและคอมพิวเตอร์ การแปลข้อความครบชุดและโหมดมืดเป็นงาน UI ที่ยังต้องเก็บต่อ

## ถ้าเปิดไม่ได้

- ถ้าบอกว่าพอร์ตถูกใช้ ให้ตรวจว่ามี JAZMINE เปิดค้างอยู่หรือไม่ ปิดตัวเก่าก่อนเปิดใหม่
- ถ้าหน้าจอบอกเชื่อมต่อไม่ได้ ให้ตรวจว่าหน้าต่างโปรแกรมยังเปิดอยู่
- ติดตั้งเครื่องมือครั้งแรกต้องมีอินเทอร์เน็ต สคริปต์จะตรวจหา Node.js 24 และ pnpm ก่อน
- หากมีข้อความผิดพลาด ส่งข้อความนั้นมาได้ โดยไม่ส่งรหัสผ่านหรือค่าจากไฟล์ `.env`

## สำหรับผู้พัฒนา

รันจากโฟลเดอร์ `JAZMINE`:

```text
pnpm install --frozen-lockfile
pnpm dev
```

คำสั่งตรวจงาน:

```text
pnpm typecheck
pnpm run lint
pnpm test
pnpm build
pnpm test:e2e
```

การทดสอบหน้าจอใช้ Edge ที่ติดตั้งอยู่บน Windows ถ้าใช้เครื่องอื่น ติดตั้ง Chromium ด้วย `pnpm exec playwright install chromium` หรือกำหนด `PLAYWRIGHT_BROWSER_EXECUTABLE` ไปยังเบราว์เซอร์ทดสอบ

ตัวทดสอบใช้ฐานข้อมูลแยกจากฐานที่คุณเปิดทดลอง ผลภาพอยู่ใน `test-results` ซึ่งไม่นำเข้าประวัติโค้ด `pnpm dev` โหลดหน้าจอที่แก้ไขใหม่ได้ แต่แก้หลังบ้านแล้วต้องหยุดและเปิดใหม่

## ฐานข้อมูลและการนำขึ้นใช้งานจริง

โหมดทดลองใช้ PGlite ซึ่งเป็น PostgreSQL แบบฝังในเครื่องและเก็บลงดิสก์ โปรแกรมเบื้องหลังในโหมดนี้ใช้การเชื่อมต่อร่วมกับ API ไม่เปิด worker แยกมาแย่งใช้ไฟล์

เตรียมตัวเชื่อม PostgreSQL ภายนอกไว้แล้วผ่าน `DATABASE_URL` แต่ยังไม่ได้ทดลองกับ PostgreSQL ภายนอกจริงในรอบนี้ เมื่อใช้ฐานภายนอกให้เปิด `pnpm worker` เพิ่ม และจัดการโครงสร้างด้วย `pnpm db:migrate`

การเปิดใช้งานจริงยังต้องจัดบริการฐานข้อมูล HTTPS การสำรอง/กู้คืน และวิธีสร้างเจ้าของบนเครื่องใช้งานจริงแยกจากหน้าตั้งค่าในเครื่อง ไม่ควรเปลี่ยนเป็นโหมด production แล้วถือว่าระบบพร้อมให้บริการทันที
