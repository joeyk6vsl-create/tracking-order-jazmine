# การเตรียมและเปลี่ยนฐานข้อมูล

ฐานข้อมูลตามแผนคือ PostgreSQL พื้นที่นี้เก็บไฟล์คำสั่งจัดโครงสร้างและข้อมูลอ้างอิงเริ่มต้น

- `migrations` — เปลี่ยนโครงสร้างข้อมูลทีละขั้นและเก็บประวัติ
- `seeds` — ใส่ข้อมูลตั้งต้น เช่น รายชื่อแผนก

ไฟล์ฐานข้อมูลจริงเก็บแยกใน `local-data/postgres` ที่ถูกละเว้นจากประวัติโค้ด รุ่นนี้มีโครงสร้างข้อมูลผู้ใช้และการเข้าสู่ระบบจริงแล้ว ใช้ PGlite ในเครื่อง และเตรียมตัวเชื่อม PostgreSQL ภายนอกไว้
