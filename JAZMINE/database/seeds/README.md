# ข้อมูลเริ่มต้น

เตรียมข้อมูลอ้างอิงที่จำเป็นเมื่อเริ่มระบบ เช่น ระดับผู้ใช้ `ADMIN_PROMAX` และ `STAFF` รวมถึงแผนก `ADMIN`, `GRAPHIC`, `PRINTING` และแผนกอื่นตามกฎกลาง

ต้องแยกข้อมูลทดสอบออกจากข้อมูลจริง ไม่ใส่รหัสผ่านกลางที่ทุกคนใช้ร่วมกันลงในไฟล์

ขณะนี้ยังไม่ได้ใส่ข้อมูลจริงหรือสร้างบัญชีเจ้าของ
