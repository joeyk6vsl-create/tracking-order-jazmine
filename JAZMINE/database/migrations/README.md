# ประวัติการเปลี่ยนโครงสร้างข้อมูล

แต่ละไฟล์ในอนาคตจะบอกว่าฐานข้อมูลต้องเพิ่มหรือเปลี่ยนอะไร เช่น เพิ่มตารางผู้ใช้หรือช่องข้อมูลออเดอร์

ใช้ชื่อเรียงตามลำดับและบอกหน้าที่ เช่น `0001_create_users.sql` เมื่อใช้งานแล้วต้องเก็บไว้เพื่อให้เครื่องพัฒนาและเครื่องใช้งานจริงเปลี่ยนตามขั้นตอนเดียวกัน

ไฟล์จริงชุดแรกคือ `0001_identity.sql` เก็บโครงสร้างบัญชี รหัส การเข้าสู่ระบบ ประวัติ และเหตุการณ์พื้นฐาน โหมดพัฒนาเปิดโปรแกรมแล้วใช้รายการที่ยังไม่เคยใช้ให้ ส่วน production ต้องสั่ง `pnpm db:migrate` แยก
