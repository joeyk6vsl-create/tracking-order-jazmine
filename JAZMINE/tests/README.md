# การตรวจความถูกต้องของระบบ

ขยาย `tests/e2e/catalog-order-entry.mjs` ให้ตรวจตารางหลายไซซ์ ผ้าแยกสามส่วน ภาพลูกค้าก่อนบันทึก จำนวน/เบอร์ไม่ถูกต้อง และผลตอบกลับหายหลังบันทึกร่างและภาพ ต้องไม่มีฉบับร่างหรือภาพซ้ำและภาพยังรออนุมัติ ก่อนตรวจความพร้อมจนยืนยันเลขออเดอร์ ใช้ฐานใหม่และพอร์ต 5193/3117 แยกจากร้าน ดู `docs/ORDER_ENTRY_MULTI_SIZE_TH.md` ส่วน QR ใช้รูปจำลอง จึงไม่ใช่หลักฐานว่ารูปจริงของร้านผ่านแล้ว

เพิ่ม QR ในใบแจ้งหนี้: `tests/integration/invoice-tracking.test.ts` และ `tests/e2e/invoice-tracking.mjs` ตรวจลิงก์ตรงออเดอร์ การอ่านโดยไม่เปลี่ยนข้อมูล สิทธิ์/เบอร์ หมดอายุ/ปิด พิมพ์ซ้ำ ฉบับเก่า หน้าจอมือถือ และอ่าน QR จากภาพ PDF จริงด้วยเครื่องมือทดสอบ ใช้ข้อมูลจำลองแยกจากร้าน

เพิ่มชุดรายการแถมล้วน `tests/integration/gift-only.test.ts` และ `tests/e2e/gift-only.mjs` ตรวจซื้อ 0 พร้อมจำนวนจริง ไม่รับรายการว่าง ซื้อครบแถม/ส่วนลด ราคาไม่ครบ ผลิตและส่งรวมแถม ออเดอร์ยอดศูนย์ และสำเนาที่กู้ ใช้ข้อมูลจำลองแยกจากร้าน

เพิ่ม `order-lifecycle.test.ts` และ `tests/e2e/order-lifecycle.mjs` ตรวจยกเลิก ตกลงยอด คืนเงินจริง เก็บ/เปิดข้อมูลเก่า รายงานย้อนหลัง และลูกค้าถามหลังเก็บ ใช้ฐานจำลองแยกจากร้านทั้งหมด ดู `docs/CANCEL_AND_ARCHIVE_ORDERS_TH.md`

เพิ่มชุดแก้จำนวนปัญหาที่ปิดแล้ว `tests/integration/issue-corrections.test.ts` และหน้าจอจริง `tests/e2e/issue-corrections.mjs` ตรวจประวัติเดิม จำนวนล่าสุด งานทดแทน การส่ง งานใช้ต่อ การแก้ผิดไซซ์ อัปเกรดข้อมูลเก่า การกู้สำเนา สิทธิ์ และการเชื่อมต่อขาด ดูคู่มือภาษาไทย `docs/CORRECT_PRODUCTION_ISSUE_QUANTITIES_TH.md`

เพิ่ม `pnpm test:load` สำหรับตรวจข้อมูลจำนวนมากและหน้าจอกับฐานจำลองในหน่วยความจำ ดู `tests/load/README.md` แยกจากการตรวจความถูกต้องรวม เพื่อไม่ให้เวลาเครื่องแต่ละเครื่องทำให้ชุดตรวจหลักผันผวน

การทดสอบจะทำไปพร้อมแต่ละส่วน ไม่รอสร้างครบแล้วค่อยเริ่มตรวจ

- `integration` — ตรวจว่าหลายส่วนทำงานร่วมกันถูกต้อง
- `e2e` — ทดลองเส้นทางผ่านหน้าจอเหมือนผู้ใช้จริง

การทดสอบกฎย่อยของแต่ละเรื่องจะอยู่ใกล้ไฟล์โปรแกรมของเรื่องนั้น เพื่อหาและแก้ไขได้ง่าย

มีชุดตรวจระบบจริงแล้ว: `pnpm test` ตรวจหลังบ้านและข้อมูลตั้งแต่บัญชีจนถึงสำรอง/กู้คืน และ `pnpm test:e2e` ตรวจเส้นทางผ่านเบราว์เซอร์เดิม W9 และ W10 ตามลำดับ ผลตรวจแบบร่างเก่าเป็นคนละชุดกับสองคำสั่งนี้ ใช้ข้อมูลทดสอบแยกจากข้อมูลของร้าน
