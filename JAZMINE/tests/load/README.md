# ตรวจข้อมูลมากและหน้าจอ — ใช้ฐานจำลองเท่านั้น

เรียก `pnpm test:load` จากโฟลเดอร์ JAZMINE จะสร้างลูกค้า 20,000 ราย ออเดอร์ 10,001 รายการและประวัติเงิน/ผลิตในหน่วยความจำ ตรวจยอด วัดเวลาผ่าน HTTP ในเครื่อง และตรวจเบราว์เซอร์ด้วยข้อมูลชุดเดียวกัน ผลอยู่ที่ `test-results/local-load-latest.json` พร้อมภาพ `volume-reports-desktop.png` และ `volume-reports-mobile.png`

ไม่อ่านค่าที่อยู่ฐานจาก `.env` และไม่รับตำแหน่งฐานจริง ข้อมูลจำนวนมากสร้างจากแบบทดสอบเพื่อวัดการอ่าน ไม่ใช่ออเดอร์จริงที่ผ่านการผลิตครบทุกใบ หลังจบปิดการเชื่อมต่อและโปรแกรมทดสอบ หน้าจอใช้ช่อง 5182 ชั่วคราว ต้องมี Edge หรือ Chromium ตามวิธีตั้งค่าใน HOW_TO_RUN_TH.md

รหัสต่อท้ายชื่อไฟล์ผล เช่น `baseline`, `optimized`, `latest` ใช้แยกรอบวัด คำสั่ง `node tests/load/local-volume.mjs baseline` ตรวจ HTTP อย่างเดียว รอบชื่ออื่นตรวจหน้าจอด้วย รันหลังสร้างส่วนหลังบ้านแล้ว

วัด 7 รอบหลังเตรียม 1 รอบ ตัวเลข p95 ในไฟล์เป็นค่าสูงสุดของตัวอย่างเล็กชุดนี้ ไม่ใช่ค่ารับรองบริการจริง ไม่ตั้งเกณฑ์เวลาตายตัวในชุดตรวจรวมเพราะเครื่องและภาระงานต่างกัน ตรวจรายการต้องแบ่งหน้า ยอดต้องตรง และคำขอต้องสำเร็จไว้เป็นข้อบังคับ

คำอธิบายผลและข้อจำกัดภาษาไทย: `docs/VOLUME_AND_CONCURRENT_USE_TH.md` กรณีบันทึกพร้อมกันอยู่ที่ `tests/integration/concurrency.test.ts` แยกจากตัววัดเวลา
