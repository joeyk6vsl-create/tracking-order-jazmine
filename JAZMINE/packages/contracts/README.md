# รูปแบบข้อมูลที่ใช้ร่วมกัน

ใช้กำหนดว่าหน้าจอส่งข้อมูลอะไรไปหลังบ้าน และหลังบ้านส่งคำตอบอะไรกลับมา เช่น ข้อมูลยืนยันออเดอร์ ยอดราคา และข้อความผิดพลาด

เมื่อรูปแบบเปลี่ยน ทั้งสองฝั่งจะตรวจความเข้ากันได้ ทำให้ลดปัญหาชื่อช่องหรือความหมายข้อมูลไม่ตรงกัน

ส่วนนี้ไม่คำนวณยอดเงินจริง ไม่อ่านฐานข้อมูล และไม่เก็บรหัสผ่านหรือค่าลับ

รุ่นนี้มี `src/identity.ts` ระบุผู้ใช้ ระดับ แผนก สิทธิ์ และข้อมูลบัญชีที่ส่งถึงกันจริงแล้ว
