# ชุดหน้าจอที่ใช้ซ้ำ

ใช้เก็บปุ่ม ช่องกรอก กล่องยืนยัน ตาราง และข้อความแจ้งสถานะที่หลายหน้าใช้ร่วมกัน เพื่อให้หน้าตาสอดคล้องกันและปรับสีหรือขนาดจากจุดเดียวได้

อ้างอิง `JAZMINE_UI_DESIGN_SYSTEM_V1.md` และ `apple-layout-guide.md` ในศูนย์เอกสารเดิม

กฎคำนวณราคา คืนเงิน และสิทธิ์จริงไม่อยู่ในส่วนหน้าตานี้

ขณะนี้ยังไม่มีส่วนหน้าจอจริง
