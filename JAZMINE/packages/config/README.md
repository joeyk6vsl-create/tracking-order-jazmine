# กติกาการพัฒนาที่ใช้ร่วมกัน

ส่วนนี้จะเก็บค่าตั้งต้นสำหรับตรวจรูปแบบไฟล์และความถูกต้องของโปรแกรม เพื่อให้หน้าจอ หลังบ้าน และงานเบื้องหลังใช้มาตรฐานเดียวกัน

ไม่ใช่หน้าตั้งค่าธุรกิจของร้าน เช่น อัตราแลกเปลี่ยน ราคาขาย หรือเงินมัดจำ และไม่เก็บค่าลับจริง

ขณะนี้ยังไม่มีชุดค่าตั้งต้นสำหรับเครื่องมือพัฒนา
