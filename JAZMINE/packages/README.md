# ส่วนที่ใช้ร่วมกัน

พื้นที่นี้เก็บของที่โปรแกรมหลายส่วนต้องใช้ตรงกัน เพื่อลดการทำซ้ำ

- `contracts` — รูปแบบข้อมูลที่ส่งถึงกัน
- `ui` — หน้าตาปุ่ม ช่องกรอก และส่วนหน้าจอที่ใช้ซ้ำ
- `config` — กติกาการพัฒนาและตรวจไฟล์

ไม่ใช้เป็นที่รวมข้อมูลลูกค้า สูตรราคา และกฎทุกเรื่อง กฎธุรกิจยังมีเจ้าของตาม Phase 0–6
